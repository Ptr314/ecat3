### Отладка и автоматизация

- [+] Добавлена система сценариев ([SCRIPTING.md](SCRIPTING.md), [#50](../../issues/50)):
  - Конфигурацию машины и сценарий можно передавать через командную строку (__--config__, __--script__).
  - Движок сценариев может использоваться как для записи демонстрационных сценариев через интерфейс, так и для отладки эмулятора.
- [+] Добавлен набор проверочных сценариев по всем машинам с эталонными результатами и раннером
  (`python tests/run_tests.py`, [tests/README.md](tests/README.md)).
- [+] Управление эмулятором снаружи по протоколу MCP ([MCP.md](MCP.md), [#54](../../issues/54)) через stdin/stdout.
  Собирается ключом __ENABLE_MCP__, по умолчанию выключен.
- [+] Консольная сборка без Qt (ключ __ENABLE_HEADLESS__): позволяет прогонять сценарии
  и проверочный набор без окон. Ключ __--no-sound__ для машин без звуковой карты.
- [+] В сценарии встроен механизм логирования состояния всех устройств.
- [+] Команда сценария __EXIT__ принимает код, который становится кодом возврата процесса
  в оконной и в консольной сборке.
- [+] Параметры процессора __debug__ и __breakpoints__ в конфигурации: машина стартует под отладчиком
  с заданными точками останова.

### Новые компьютеры и устройства

- [+] Клоны «Ириши» &ndash; «Диалог» и «Каспий».
- [+] Компьютеры «Электроника БК0010» и «БК0010-01»:
  - Процессор К1801ВМ1 и заготовка под К1801ВМ2. Проходит тест CPUTEST2 Алексея Савельева.
  - Дизассемблер и отладчик PDP-11.
  - Дисплейный контроллер БК (__bk-display__): 512x256 монохромный и 256x256 цветной режимы,
    режим четверти экрана.
  - Загрузка программ БК из файлов *.bin с заголовком адреса загрузки.
  - Программируемый таймер (__bk-timer__), регистры 0177706-0177712. Реализован делитель частоты счета 
    (разряды 5-6 регистра управления), режимы кольцевого и однократного счета.
  - Магнитофон &ndash; чтение и запись. Понимает текстовый формат БЕЙСИКа (_*.asc_, формат ленты _bk-ascii_) 
    с записью программ нумерованными частями по 256 байт с контрольной суммой.
- [+] Компьютер «Электроника БК0011М»:
  - Страничное ОЗУ 128 КБ и переключаемые ПЗУ в окне 0100000.
  - Две экранные страницы и шестнадцать палитр.
  - Кадровое прерывание 50 Гц по вектору 0100 с запретом разрядом 14 регистра 0177662.
  - Отдельная отладочная конфигурация с модулем МСТД, запускающая встроенные тесты машины.
- [+] БК: Контроллер дисковода (__bk-fdc__, КНГМД на К1801ВП1-128, регистры 0177130 и 0177132)
  с ПЗУ дискового драйвера DISK 326.
  - На БК0010-01 блок добавляет 16 КБ ОЗУ, подключаемые на место штатного Бейсика.
- [+] БК: Звуковой генератор AY-3-8910 (устройство __ay8910__): три тональных канала, шум, огибающая.
- [+] БК: Джойстик (__joystick__) на порту 0177714. 
- [+] Экранная клавиатура: окно с рисунком клавиатуры целевой машины в формате SVG. 
  Работает и в оконной версии, и в браузере. 
  - БК0010 &ndash; своя пленочная клавиатура с клавишами ГРАФ, ЗАП, СТИР, УСТ ТАБ, СБР ТАБ и диагональными стрелками.
  - Микроша &ndash; первая машина со сканирующей клавиатурой на рисунке: клавиша замыкает свой контакт матрицы,
    лампа РУС горит по индикатору машины.
  - Апогей БК-01, Радио-86РК, Спектр-001 и все версии Ориона-128 &ndash; общий рисунок клавиатуры
    Апогея и общая таблица клавиш `data/rk.keys` по матрице `rk.kbd`. У Апогея подключена линия
    индикатора РУС (PC3), без которой РУС/ЛАТ на рисунке не переключала бы регистр.

### Улучшения базовых устройств

- [~] Видеоконтроллер __i8275__ (КР580ВГ75) и контроллер ПДП __i8257__ (КР580ВТ57) эмулируются по циклам,
  машины семейства Радио-86РК перестали работать быстрее оригиналов ([#33](../../issues/33)):
  - ВГ75 ведет собственный растр по символьным тактам.
  - ВТ57 выдает адреса из регистров канала, считает переданные байты,
    выставляет признак конца счета и перезагружает каналы в режиме автозагрузки.
  - На время каждого цикла ПДП процессор снимается с шины. 
    Регенерация экрана забирает около 26% процессорного времени на компьютерах семейства Радио 86РК.
  - Экран собирается из байтов, которые ПДП действительно прочитал, ряд за рядом в момент вывода.
  - Ленточные подпрограммы гасят экран запретом канала ВТ57: пока идет запись
    или чтение ленты, ПДП не отбирает такты и экран черный.
- [+] Восьмеричная запись чисел с префиксом __&amp;__ (например, __&amp;177714__) в конфигурациях и сценариях.
  Используется для машин на К1801ВМ1, и в этой же записи их печатает __LOG__.
  - Параметр __radix__ в секции __system__ задает систему счисления, в которой записаны все числа файла
  без префикса; сценарий берет ее у загруженной машины, а команда __RADIX__ переопределяет. Десятичные
  значения (частоты, размеры, задержки) помечаются префиксом __\___. 
- [+] У диапазонов __memory-mapper__ появился признак __strict__: диапазон отвечает только на обращения своего
  режима, остальные дают тайм-аут магистрали. Используется в БК для различения БК0010 от БК0011М.
- [~] Дисковод __fdd__ в логическом режиме принимает образы короче объявленной геометрии (образы БК на 40 дорожек)
  и сохраняет файлы _*.img_ и _*.bkd_; появилось свойство __generation__ для сценариев.
- [+] У устройства __port__ появился второй банк регистра (__alt_bit__, __alt_default__, интерфейс __~alt__):
  за одним адресом стоят два регистра, и разряд записываемого значения выбирает, в какой из них попадет запись.
- [+] У устройства __map-keyboard__ появился выход __~pressed__ &mdash; признак удерживаемой клавиши.
- [~] Формат ленты в секции __[TapeFiles]__ можно задавать отдельно для машины
  записью вида __&lt;тип системы&gt;.&lt;расширение&gt;__, которая имеет приоритет над общей.
- [~] Параметр магнитофона __ecoding__ переименован в __encoding__: в 3.5 он читался с опечаткой,
  и заданное в конфигурации значение молча игнорировалось.
- [+] Добавлен словный (16-разрядный) доступ к шине для процессоров с 16-битной шиной данных.
  Устройство __port__ с параметром __size__ больше 8 может работать как двухбайтный регистр.
- [~] Звук: исправлены щелчки при старте.
- [+] Устройство __mux__ (мультиплексор): выдает на выход один из двух входов по управляющей линии.
  Используется в «Ирише + КНГМД», где порт B ВВ55 по разряду PC7 читает то состояние контроллера, то константу $FF.
- [+] У устройства __port__ появился параметр __access_mode__ (_r_, _w_, _rw_): какие обращения вызывают
  срабатывание интерфейса __~access__. По умолчанию &ndash; и чтение, и запись.
- [~] Образ ПЗУ короче отведенного окна повторяется по всему окну, как на реальной плате
  с недешифрированными старшими линиями адреса.
- [~] Управляющее слово ВВ55 (i8255) сбрасывает выходные регистры портов, как в документации на микросхему.
  Агат-9 теперь корректно выполняет теплый перезапуск из программы, оставившей выбранным второй дисковод
  (например, «Конец работы» в «Школьнице»).
- [~] Процессор 6502: исправлены недокументированные команды ARR и ISB &ndash; они проверяли флаг B
  вместо флага десятичного режима D.

### Интерфейс

- [~] В окне выбора машины отладочные конфигурации включаются флажком, а не только ключом
  __show_debug_versions__ в ini-файле; двойной щелчок по модели снова открывает ее.
- [+] Щелчок по значку параметра машины на панели инструментов переключает его значение
  (например, видеорежим).
- [+] Панель инструментов для записи/воспроизведения сценариев. Может отключаться через меню &laquo;Параметры&raquo;.
- [+] Порядок машин внутри группы задается параметром __order__ в разделе __system__ конфигурации:
  сначала по нему, потом по алфавиту. Сами группы остаются в алфавитном порядке. Тот же порядок
  использует список веб-сборки.
- [+] Кнопка пуска и останова процессора на панели инструментов; ее значок показывает текущее состояние.
- [~] Диалоги открытия файлов по умолчанию начинают с каталога __software__.
- [~] Ошибки в конфигурации машины выводятся сообщением с причиной вместо аварийного завершения.
- [~] Исправлена гонка при одновременной записи настроек в ini-файл.
