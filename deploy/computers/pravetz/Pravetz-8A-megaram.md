# Правец-8А с MEGARAM 1 Мб

В разъеме X0 модуль MEGARAM на&nbsp;1&nbsp;Мб: 16 страниц по&nbsp;64&nbsp;Кб. Страница выбирается записью ее&nbsp;номера в&nbsp;$C073 (как у&nbsp;RamWorks), видео всегда показывает первую. Так память использует виртуальный диск СП «Вариант».

Виртуальный диск&nbsp;&ndash; программа `VIRD` на&nbsp;школьном диске `p8ru02.dsk` (в&nbsp;`software/pravetz`): `BRUN VIRD` делит 1&nbsp;Мб на&nbsp;шесть дисков, это дисководы `D1`&ndash;`D6` слота 3 (`CATALOG,S3,D4`). Диски уже размечены; F2, нажатая при запуске, размечает их заново, а&nbsp;F1 включает щелчок динамика при каждом обращении.

Информацию о компьютере см. в описании основной конфигурации.
