# eCat &mdash; a universal emulator of retro computers

The project was created in support of the Russian-language emulation encyclopedia [Emuverse.ru](https://emuverse.ru).

---

Choose a computer in the panel on the left — a short description appears on the right, with links to further materials and to software you can download.


Every computer comes with a minimal set of programs, enough to start it and to begin using it.

---

Detailed documentation is on the project page on [GitHub](https://github.com/Ptr314/ecat3).
