# ДВК-3 с КЦГД

ДВК-3 (МС1201.02, КМ1801ВМ2) с контроллером цветного графического
дисплея КЦГД вместо терминала КСМ.

КЦГД - графический терминал на плате магистрали: свой процессор
КМ1801ВМ2 с прошивкой 181, 128 КБ видеопамяти, экран 800 x 480 точек
в 16 цветах, своя клавиатура МС7004. С машиной он связан линией ИРПС.

После включения монитор ДВК отвечает приглашением `@`; команда `BMX`
грузит RT-11 с дискеты MX, как на ДВК-3 с КСМ.

Текст прошивки 181 - жёлтый.

Мышь КЦГД подключена: щелчок по экрану захватывает указатель, Ctrl+Alt
отпускает. Прошивка её не читает - читают программы, которые машина
загружает в КЦГД.

Клавиатура - как у ДВК-3.
