# ДВК-3

Диалоговый вычислительный комплекс на процессорной плате МС1201.02
(КМ1801ВМ2) с терминалом КСМ, клавиатурой МС7004 и двумя дисководами MX.

После включения процессор входит в пультовый режим, и монитор (ПЗУ 055)
отвечает приглашением `@`. Первые символы монитор шлёт, пока терминал ещё
готовится, поэтому приглашение появляется после нажатия ВК.

## Загрузка с дискеты

В приводе 0 - RT-11SJ V05.04 с драйвером MX V02.2. Команда монитора

    @BMX

грузит систему; загрузочный командный файл доходит до программы DAY - ВК
принимает дату и время. Командный файл назначает DK на привод MX1, который
пуст: для работы с системной дискетой - `ASS MX0 DK`.

## Клавиатура

| Хост | Машина |
|---|---|
| Shift, Ctrl, Caps Lock | ВР, СУ, ФКС |
| Alt | РУС/ЛАТ |
| Esc | Ф11 (АР2, ESC) |
| F1&ndash;F4 | ПФ1&ndash;ПФ4 |
| F5&ndash;F9 | СТОП КАДР, ПЕЧАТЬ КАДРА, ПАУЗА, УСТ РЕЖИМА, Ф5 |

Латинские буквы стоят на клавишах с той же латинской надписью; в русском
регистре получается ЙЦУКЕН самой МС7004.
