# BK-0011M + MSTD

A BK-0011M with the MSTD module plugged into the MPI bus connector: the monitor system
of test diagnostics (ROM at addresses 0160000-0177577). It takes over the start, so the
machine starts in the test menu instead of BASIC.

The menu offers checks of the RAM (with all eight pages and the page dispatcher), the
ROM, the keyboard, the tape interface, the I/O port, the timer and the palette. Choose
an item with the arrows and the ВВОД (Enter) key.
