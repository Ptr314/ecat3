# BK-0010 (FOCAL)

An early version of the Elektronika BK-0010 with FOCAL and tests in ROM instead of BASIC.

* Processor: K1801VM1, 3 MHz.
* RAM: 16 KB main + 16 KB video memory.
* ROM: Monitor (0100000), FOCAL (0120000), tests (0160000).
* The on-screen keyboard is the membrane keyboard of this model.

## Some FOCAL commands

* `P M` &mdash; exit to the Monitor.
* `P T` &mdash; go to the test menu.

Everything else is as on the BK-0010-01.
