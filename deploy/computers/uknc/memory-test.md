# Тест памяти УК-НЦ

Отладочная конфигурация для проверки памяти УК-НЦ. Образы ПЗУ не нужны:
всё, что надо, кладёт в память сценарий. Настоящей машины здесь нет &mdash;
процессор стоит.

Проверяются три механизма, на которых держится вся память машины:

* **plane-pair** &mdash; адресное пространство центрального процессора поверх
  планов 1 и 2: слово по адресу A это байт A/2 плана 1 плюс байт A/2 плана 2,
  поэтому 64 КБ адресов стоят по 32 КБ каждого плана;
* **indirect-memory** &mdash; косвенный доступ периферийного процессора к плану 0
  и к памяти центрального, с защёлкой, которая обновляется только записью в
  регистр адреса;
* **or_read** &mdash; окно, где ПЗУ и ОЗУ отвечают на чтение одновременно, а
  шина видит их объединение по ИЛИ; запись при этом доходит только до ОЗУ.

Смотреть надо не на экран, а на журнал сценария
`tests/scripts/boot-uknc-memory.ecat`.
