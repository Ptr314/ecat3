# Тест дисплея УК-НЦ

Отладочная конфигурация для проверки дисплейного контроллера. Образы ПЗУ не
нужны: таблицу строк и сами точки кладёт в план 0 сценарий
`tests/scripts/boot-uknc-display.ecat`, процессоры крутят холостой цикл.

Видеоконтроллер обходит связный список построчных дескрипторов («таблицу
строк») в плане 0 с адреса `0000270`. Каждая строка называет адрес своих точек,
а четырёхсловные дескрипторы по ходу луча меняют палитру, растяжку, яркость и
курсор &mdash; поэтому у каждой строки могут быть свои восемь цветов и своя
ширина.

Точка &mdash; три бита, по одному из каждого плана, считанных по одному и тому
же адресу: план 0 &mdash; младший разряд цвета, план 2 &mdash; старший, а
разряд 0 байта &mdash; самая левая точка октета. Поэтому байты `252`, `314` и
`360` в планах 0, 1 и 2 дают подряд все восемь цветов.

Сценарий строит таблицу из четырёх дескрипторов &mdash; двухсловного, палитры,
параметров и замкнутого самого на себя &mdash; и снимает два экрана: с
растяжкой 1 (640 точек в строке) и с растяжкой 4 (160 точек, каждая вчетверо
шире).
