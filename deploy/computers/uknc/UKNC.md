# УК-НЦ (Электроника МС-0511)

Учебный компьютер на **двух** процессорах КМ1801ВМ2: центральный (8 МГц) и
периферийный (6,25 МГц). 

## Клавиатура

| Хост | Машина |
|---|---|
| Shift, Ctrl, Alt, Caps Lock | НР, УПР, ГРАФ, ФИКС |
| Esc | АР2 |
| F1&ndash;F5 | К1&ndash;К5 |
| F6 | АЛФ &mdash; пока нажата, действует другой алфавит |
| F7, F8, F9 | ПОМ, ИСП, УСТ |
| F10 | СБРОС &mdash; это очистка экрана, а не сброс машины |
| F12 | СТОП &mdash; ПЗУ ставит по ней HALT центральному процессору |

## Загрузка с дискет

В два привода вставлены дискеты с системными и прикладными программами.
Привод для загрузки выбирают в меню:
**1** (пункт «диск»), **стрелка вправо** (поле номера привода), **цифра
привода**, **ВК**. Без выбора номера грузится привод 0.

| Привод | Дискета | Что на ней |
|---|---|---|
| 0 | `sysimage.dsk` | FODOS с системными утилитами: MACRO, LINK, LIBR, SRCCOM, BINCOM, DUMP, BUP, редактор EDIK, шрифты. `RU TEST` &mdash; заводская «Проверка функционирования УК НЦ» |
| 1 | `sys1002.dsk` | RT-11: DIR, PIP, DUP, NED, HELP, Паскаль, форматирование дискет (`RU MZTEST`) |

Третья дискета, `basic.dsk`, вставляется через меню привода: FODOS и дисковый
Бейсик (Вильнюс, 1988). Программа DAY спрашивает дату, после ВК стартует
Бейсик.

__Примечание:__ Из STARTS.COM на `sysimage.dsk` убраны KBS и ALTNUM. 
Обе программы оставляют резидент в памяти периферийного процессора, 
что ломает заводской тест. Запустить их можно вручную: `RU KBS`, `RU ALTNUM`.

## Загрузка из картриджа

В первый слот вставлен картридж ПЗУ с кассетным Бейсиком (Вильнюс, 1988).
Загрузка с него &mdash; пункт **2** («кассета ПЗУ»), **ВК**: номер кассеты 1
предлагается по умолчанию. Второй слот пуст.

## Магнитофон

Программы Бейсика пишутся на ленту командой `SAVE "ИМЯ"` и читаются командой
`LOAD "ИМЯ"`, как на машине: сначала команда, потом кнопка воспроизведения в
окне магнитофона. Запись сохраняется файлом _*.uknc.tap_, в нём лежат файлы ленты
подряд с их заголовками. Программы в машинных кодах грузятся пунктом **5** меню
ЗАГРУЗКА, **ВК**, и затем кнопкой воспроизведения: ПЗУ читает с ленты загрузчик,
а тот &mdash; саму программу. Так проверена игра «Кот-рыболов».

Запись настоящей кассеты в WAV переводится в _*.uknc.tap_ программой
`software/uknc/wav2uknc.py` (нужен Python 3): `python wav2uknc.py запись.wav`.
Она проверяет контрольные суммы и печатает, какие файлы нашлись на ленте.

Заводской «Тест магнитофона (ЗАГЛ.)» ждёт заглушку, которая замыкает выход на
вход. В эмуляторе она вставляется командой сценария `COMMAND tape-plug.set(0,1)`.
