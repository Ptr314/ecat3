# Orion-128
## The main version on the KR580VM80

The ROM disk and floppy drives are connected. To boot from a floppy drive, run the program BOOT (or DOS).

## Working in ORDOS.

### Option 1 (fast).

You can simply open *.bru, *.ord and *.rko files: they are loaded into the RAM disks as long as there is room. After opening a file, refresh the list (you can press "Soft restart").

### Option 2. Loading through the tape recorder.

1. Start the program CH4.
2. Open the tape recorder window and choose a file in the *.rko format.
3. Start playback.
4. Switch to the main window and press Enter. The program loads into the electronic disk.
5. Leave CH4 with F4, move with the arrows to the panel you need and start the program.

## Working in CP/M.

Run the program BOOT or DOS (depending on the CP/M version). Disk images are chosen with the buttons on the toolbar.

## Keyboard:

* РУС/ЛАТ (Cyrillic/Latin): Caps Lock.
* НР: Shift, УС: Ctrl.
* ВК (carriage return): Enter, ПС (line feed): Enter on the numeric keypad.
* ЗБ: Backspace, ТАБ: Tab, АР2: Esc, СТР (clear screen): Delete, &#8598;: Home.
* F1&ndash;F4 and the arrows: the keys of the same name.
* Letter, digit and symbol keys &mdash; as on a standard QWERTY keyboard with the English layout.
* Ctrl-Break &ndash; reset, Ctrl-Alt-Break &ndash; cold restart.
* The machine's keyboard can be opened as a picture: the menu «Emulation &rarr; Keyboard».
