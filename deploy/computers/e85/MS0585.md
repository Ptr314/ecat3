# Электроника МС 0585 (Электроника-85)

Персональная ЭВМ, советский аналог DEC Professional 350: процессор КМ1811ВМ1 (F-11)
с адаптером плавающей запятой, 512 КБ ОЗУ, видеоконтроллер НВ1 с расширителем
НВ2 (1024 x 256 точек, 8 цветов из 256), контроллер дисковода на микроЭВМ 8751,
клавиатура МС7004.

После включения автотест ПЗУ проверяет машину и выводит надпись «ЭЛЕКТРОНИКА», затем
загружает систему с дискеты в приводе 0, а с пустым приводом показывает значок дискеты
с вопросом. Если автотест нашёл неисправность, на экране рисунок
системного блока, номер позиции, код ошибки и код устройства. Проверка занимает
около 20 секунд.

## Загрузка

В приводе 0 стоит дискета `pros-d-1.8-system.dsk`: после автотеста загружается
операционная система ПРОС(Д) 1.8. Полная система ПРОС 2.03 работает с винчестера,
это отдельная конфигурация «МС 0585 с винчестером».

## Звук

Единственный источник звука &mdash; пьезозвонок в клавиатуре: при включении машины звучат
два коротких сигнала, удерживаемая клавиша щёлкает на каждом автоповторе. 
Звонок в ПРОС выключен, включается в меню установки режимов:
Scroll Lock, стрелками на «Звонок включен», ВЫБР (End), выход - ПРОДОЛЖ.

## Дискеты

В поставку эмулятора входит `pros-d-1.8-system.dsk`, остальные образы &mdash; в
[библиотеке программ на сайте эмулятора](https://ecat.emuverse.ru/library/e85/). Все дискеты по
400 КБ, 80 дорожек по 10 секторов:

| Файл | Содержимое |
|---|---|
| `pros-d-1.8-system.dsk` | ПРОС(Д) 1.8, система |
| `tpo-1.dsk`, `tpo-2.dsk` | тестовые программы (меню «Техническое обслуживание») |
| `pros-2.03-1-system.dsk` ... `pros-2.03-5-utilit.dsk` | установка ПРОС 2.03 на винчестер |
| `igra.dsk`, `igra-color.dsk` | игры для НВ1 и для цветного монитора с НВ2, ставятся на винчестер из ПРОС 2.03 |
| `rt11-sj.dsk` | RT-11 SJ, с этим ПЗУ не загружается: загрузчик рассчитан на другое ПЗУ |
| `emul-1.3.hfe` | «Эмулятор DOS v 1.3» для платы МС 1702, дискета с мечеными секторами (метки восстановлены по коду установщика) |
| `format-2.0.dsk` | «Форматирование дискет v 2.0», ставится на винчестер. Размечает дискеты только на прошивке «КОЧАН, форматирующая», она выбирается в редакторе конфигурации: на штатной программа сообщает об успехе, но ничего не размечает |
| `start-1.dsk` ... `start-5.dsk` | пакет СТАРТ: оконная среда и её программы, ставятся на винчестер. Вторую дискету установка просит в привод 2. Проверены сама среда и запуск «Электронного листа» |

Дисковод принимает и образы `.hfe`: в них хранятся метки секторов, которых нет в `.dsk`.

После загрузки ПРОС(Д) просит вставить дискету с прикладной программой. Чтобы
запустить тесты, вставьте в привод 0 `tpo-1.dsk` и нажмите ПРОДОЛЖ, а на запрос
второй дискеты вставьте `tpo-2.dsk` в привод 1 и снова нажмите ПРОДОЛЖ. В меню
выбирайте стрелками, запуск - ИСП, возврат - ВЫХОД.

## Клавиши

| Клавиша ПК | МС7004 |
|---|---|
| F1-F4 | ПФ1-ПФ4 |
| F5 | ДОП ВАРИАНТ |
| F6, F7, F8 | ПРЕРЫВ, ПРОДОЛЖ, ОТМЕН |
| F9, F10 | ОСНОВН КАДР, ВЫХОД |
| F11, F12 | ПМ, ИСП |
| Home, Insert, Delete | НТ, ВСТ, УДАЛ |
| End | ВЫБР |
| Page Up, Page Down | ПРЕД КАДР, СЛЕД КАДР |
| Scroll Lock | УСТ РЕЖИМА |
| цифровой блок при включённом Num Lock | цифровой блок МС7004 |

Остальные клавиши МС7004, например СТОП КАДР и ПАУЗА, нажимаются на экранной клавиатуре:
кнопка с клавиатурой на панели инструментов.

В ПРОС цифры верхнего ряда набираются с ВР (Shift) или при включённой ФКС (Caps Lock): без
них клавиша `1` даёт `!`, `2` даёт `"`. Так устроена таблица клавиш самой ПРОС: клавиатура
передаёт только код клавиши. Заглавные латинские буквы тоже набираются при включённой ФКС.

## Печать

Всё, что машина выводит на разъём «Печать», видно на вкладке «Печать» окна «Порты ввода-вывода»
(меню «Эмуляция»): образец из «Проверки печатающего устройства», файлы из меню «Обслуживание
печати», кадр по клавише ПЕЧАТЬ КАДРА (она есть на экранной клавиатуре). Кнопка записи сохраняет
принятое в файл, байт в байт: ПРОС выводит русский текст в КОИ-7 с переключением SO/SI, окно
показывает его уже перекодированным. Принтер всегда готов. Настоящий принтер или другой компьютер
подключаются параметром `port` устройства `prn` в редакторе конфигурации: `COM5`, `/dev/ttyUSB0`.

## Что ещё не работает

- Связь наружу: коммуникационный порт работает только в петле, как при проверке
  системного блока.
