# Электроника МС 0585 с МС 1702

[Электроника МС 0585 с винчестером](MS0585-NMD.md) и сопроцессором МС 1702 в пятой позиции
магистрали. МС 1702 - плата с процессором К1810ВМ86 на 5 МГц, 512 КБ своего ОЗУ, BIOS в
ПЗУ и видеопамятью 16 КБ, по сути IBM PC без внешних устройств. Экран, клавиатуру и диски
ей обслуживает программа «PC Эмулятор» (EMUL.TSK) на процессоре комплекса: каждый цикл
ввода-вывода и каждая запись в видеопамять идут через неё. На плате работают MS-DOS 3.30 и
русская Chi-DOS 3.30, режимы CGA текстовые и графические.

## Запуск

1. Вставьте в гнездо винчестера копию `pros-2.03-10m-pc.rd`: это система с играми
   из [конфигурации с винчестером](MS0585-NMD.md), в которой уже установлен «PC Эмулятор».
   Файл машина меняет при каждой загрузке. В поставку эмулятора он не входит, его и дискеты
   ниже можно скачать из библиотеки программ на сайте эмулятора (https://ecat.emuverse.ru).
2. Включите машину. Автотест проверяет и плату: при ошибке будет рисунок системного блока с
   кодом устройства 000061. Через 40 секунд появится Основное меню. Привод 0 в это время
   должен быть пуст: с дискетой в нём ПЗУ загрузится с дискеты.
3. Вставьте в привод 0 дискету с DOS.
4. Дополнительное меню, Б меню, PC Эмулятор, ИСП. После теста памяти (около минуты) DOS
   спросит дату и время, ВК оставляет их без изменений.

Выход из эмулятора в ПРОС - Ф17, на клавиатуре ПК Pause.

Виртуальный диск хранится в файле `[USERFILES]IBMDSK.DAT`, эмулятор создаёт его при первом запуске
и закрывает при выходе. Если выключить машину в самом первом сеансе, файл останется незакрытым, и
следующий запуск эмулятора остановится на чёрном экране. Остальной образ при этом цел: перезапустите
машину, в меню «Обслуживание файлов» выберите «Удалить файл(ы)» и удалите IBMDSK, эмулятор создаст
его заново. Содержимое виртуального диска пропадёт. Если файл хотя бы раз закрывался штатно,
выключение внутри эмулятора ему не мешает: записанное до выключения остаётся на месте.

## Дискеты

Образы - в библиотеке программ на сайте эмулятора:

| Файл | Содержимое |
|---|---|
| `eldos-msdos-3.30.dsk` | MS-DOS 3.30, системная: FDISK, FORMAT, SYS, XCOPY |
| `eldos-msdos-utils.dsk` | утилиты MS-DOS 3.30: DEBUG, CHKDSK, EDLIN, MORE, BACKUP и другие |
| `eldos-chi-dos-3.30.dsk` | Chi-DOS 3.30, системная, сообщения по-русски, накопители называются 1:, 2:, 3:, 4: |
| `eldos-emulator.dsk` | установочная дискета «PC Эмулятор в.1.1», нужна только для другого образа винчестера |

Дисковод A: - привод 0, B: - привод 1. Дискеты 180 КБ и 360 КБ лежат на дискете Э-85 в
формате 80 дорожек по 10 секторов, форматировать их нужно в ПРОС. C: - та же дискета, что и A:.

Чтобы поставить эмулятор на свой образ, вставьте `eldos-emulator.dsk` и выберите
«Обслуживание диска/дискетов», «Установить прикладную программу». Для программы нужно свободное
место в одном из меню.

## Виртуальный винчестер

Жёсткий диск DOS - файл на винчестере ПРОС. В этой конфигурации он называется D:, хотя
руководство эмулятора пишет C:.

1. Загрузите DOS с `eldos-msdos-3.30.dsk` и запустите FDISK.
2. Создайте основной раздел, от предложения занять весь диск откажитесь: FDISK показывает 305
   цилиндров, а файл должен поместиться в свободное место ПРОС. Цилиндр - 68 блоков, свободные
   блоки показывает «Обзор состояния». Вводите цифры не торопясь: поле появляется не сразу.
3. Сделайте раздел активным и выйдите из FDISK: машина перезапустит DOS.
4. `FORMAT D:/S`, затем выход из эмулятора (Pause).

После этого эмулятор без дискеты в приводе загружает DOS с D:.

## Клавиатура

Раскладка остаётся раскладкой МС 7004. Клавиши DOS, по таблице из руководства эмулятора:

| DOS | МС 7004 | На ПК |
|---|---|---|
| F1-F4 | СТОП КАДР, ПЕЧАТЬ КАДРА, ПАУЗА, УСТ РЕЖИМА | экранная клавиатура; F4 - Scroll Lock |
| F5 | Ф5 | экранная клавиатура |
| F6-F10 | ПРЕРЫВ, ПРОДОЛЖ, ОТМЕН, ОСНОВН КАДР, ВЫХОД | F6-F10 |
| Esc | Ф11 | Esc |
| Ctrl, Shift | СУ, ВР | Ctrl, Shift |
| Caps Lock | ФКС | Caps Lock |
| Alt | КМП, нажимается дважды | экранная клавиатура |
| Num Lock, Scroll Lock | ПФ1, ПФ2 | F1, F2 |
| переключение кодовой таблицы | Ф20 | Print Screen |
| выход в ПРОС | Ф17 | Pause |

В Chi-DOS русские буквы включает клавиша РУС/ЛАТ, на ПК Alt. Команды работают и по-русски:
КАТ вместо DIR, таблицу держит её драйвер `SYSTEM.SYS`.

Стрелки, СЛЕД КАДР (Pg Down), ВСТ (Ins) и УДАЛ (Del) работают как на ПК. Home, End, Pg Up и 5 есть
только на цифровом блоке: на ПК это цифровой блок при включённом Num Lock.

## Что отличается от настоящей машины

- Образ BIOS `mc1702.rom` отличается от дампа платы тремя байтами (FF284h, FF286h, FF287h), в
  каждом один разряд. С дампом как есть прокрутка стирает экран, а CLS его не чистит, с любой из
  трёх версий эмулятора на дискетах. Подробности в `docs/dev/machines.md`.
- Время памяти посчитано по схеме платы: ОЗУ 6 тактов ожидания на чтение и 7 на запись, ПЗУ и
  видеопамять без ожидания. Регенерация не учтена, а замеров настоящей платы нет, поэтому
  скорость программ на плате - оценка.
- `intr_delay = 70` возмещает то, что команды здесь выполняются целиком. Из этого числа 55 тактов
  посчитаны, остальное подобрано с запасом, чтобы проходил тест платы из её ПЗУ. На INTR
  процессор платы теряет около 14 мкс, которых на плате нет.
- Сопроцессора К1810ВМ87 нет, его команды пропускаются.
- «Эмулятор DOS v 1.3» защищён от копирования мечеными секторами и привязывается к номеру
  машины, поэтому он ставится только с `emul-1.3.hfe`: файл `.dsk` меток не хранит. На
  этой дискете есть и «Форматирование дискет v 2.2», но оно не ставится: `MODIF.TSK` завершается с
  ошибкой, а по описанию программе нужен адаптер ГМД-130.
- `emul-1.3.hfe` - не снимок настоящей дискеты: она собрана из образа `.dsk`, а метки выведены из
  кода установщика. Настоящая дискета не читалась.
- Образ дискеты версии 1.2 (`004`) повреждён и привязан к другой машине: с него эмулятор не
  ставится. С исправленной копии он загрузил MS-DOS 3.30.
