# Elektronika MS 0585 with MS 1702

[Elektronika MS 0585 with a hard disk](MS0585-NMD.en.md) and the MS 1702 coprocessor in the fifth
bus slot. MS 1702 is a board with a K1810VM86 (8086) at 5 MHz, 512 KB of its own RAM, a BIOS in
ROM and 16 KB of video memory: an IBM PC without any peripherals. The screen, keyboard and disks
are served by the "PC Emulator" program (EMUL.TSK) on the main processor: every I/O cycle and
every write to video memory goes through it. The board runs MS-DOS 3.30 and the Russian
Chi-DOS 3.30, in CGA text and graphics modes.

## Starting

1. Put a copy of `software/e85/pros-2.03-10m-pc.rd` into the hard disk slot: the system with
   games from the [hard disk configuration](MS0585-NMD.en.md), with the PC Emulator installed.
   The machine changes this file on every boot.
2. Switch the machine on. The self test checks the board too: a fault shows the picture of the
   system unit with device code 000061. The main menu appears in 40 seconds. Drive 0 must be
   empty at this time: with a floppy in it, the ROM boots from the floppy.
3. Put a DOS floppy into drive 0.
4. Дополнительное меню, Б меню, PC Эмулятор, ИСП. After the memory test (about a minute) DOS
   asks for the date and time, ВК leaves them unchanged.

Ф17 leaves the emulator for PROS, Pause on a PC keyboard.

The virtual disk is kept in the file `[USERFILES]IBMDSK.DAT`, which the emulator creates on its first
start and closes on exit. If the machine is switched off during the very first session, the file
stays unclosed, and the next start of the emulator stops on a black screen. The rest of the image is
intact: restart the machine, choose «Удалить файл(ы)» in «Обслуживание файлов» and delete IBMDSK,
and the emulator creates it again. The contents of the virtual disk are lost. Once the file has been
closed properly, switching off inside the emulator does not harm it: what was written stays there.

## Floppies

Images in `software/e85`:

| File | Contents |
|---|---|
| `eldos-msdos-3.30.dsk` | MS-DOS 3.30, system disk: FDISK, FORMAT, SYS, XCOPY |
| `eldos-msdos-utils.dsk` | MS-DOS 3.30 utilities: DEBUG, CHKDSK, EDLIN, MORE, BACKUP and others |
| `eldos-chi-dos-3.30.dsk` | Chi-DOS 3.30, system disk, messages in Russian, drives are named 1:, 2:, 3:, 4: |
| `eldos-emulator.dsk` | installation floppy of PC Emulator 1.1, needed only for another hard disk image |

Drive A: is drive 0, B: is drive 1. The 180 KB and 360 KB disks lie on an E-85 floppy of 80
tracks of 10 sectors, and such a floppy has to be formatted in PROS. C: is the same floppy as A:.

To put the emulator on your own image, insert `eldos-emulator.dsk` and choose «Обслуживание
диска/дискетов», «Установить прикладную программу». The program needs a free place in a menu.

## Virtual hard disk

The DOS hard disk is a file on the PROS hard disk. In this configuration it is D:, although the
emulator's manual says C:.

1. Boot DOS from `eldos-msdos-3.30.dsk` and run FDISK.
2. Create a primary partition and refuse the offer to use the whole disk: FDISK shows 305
   cylinders, and the file has to fit into the free space of PROS. A cylinder is 68 blocks, the
   free blocks are shown by «Обзор состояния». Type the digits slowly: the field appears late.
3. Make the partition active and leave FDISK: the machine restarts DOS.
4. `FORMAT D:/S`, then leave the emulator (Pause).

After that the emulator without a floppy in the drive boots DOS from D:.

## Keyboard

The layout stays that of the MS 7004. DOS keys, by the table in the emulator's manual:

| DOS | MS 7004 | On a PC |
|---|---|---|
| F1-F4 | СТОП КАДР, ПЕЧАТЬ КАДРА, ПАУЗА, УСТ РЕЖИМА | on-screen keyboard; F4 is Scroll Lock |
| F5 | Ф5 | on-screen keyboard |
| F6-F10 | ПРЕРЫВ, ПРОДОЛЖ, ОТМЕН, ОСНОВН КАДР, ВЫХОД | F6-F10 |
| Esc | Ф11 | Esc |
| Ctrl, Shift | СУ, ВР | Ctrl, Shift |
| Caps Lock | ФКС | Caps Lock |
| Alt | КМП, pressed twice | on-screen keyboard |
| Num Lock, Scroll Lock | ПФ1, ПФ2 | F1, F2 |
| switch of the code table | Ф20 | Print Screen |
| leave for PROS | Ф17 | Pause |

In Chi-DOS the РУС/ЛАТ key, Alt on a PC, switches to Russian letters. Commands also work in
Russian: КАТ for DIR, the table is in its `SYSTEM.SYS` driver.

Arrows, СЛЕД КАДР (Pg Down), ВСТ (Ins) and УДАЛ (Del) work as on a PC. Home, End, Pg Up and 5 are
on the keypad only: the PC keypad with Num Lock on.

## Differences from the real machine

- The BIOS image `mc1702.rom` differs from the board's dump in three bytes (FF284h, FF286h,
  FF287h), one bit in each. With the dump as it is, scrolling wipes the screen and CLS does not
  clear it, with any of the three emulator versions on the floppies. See `docs/dev/machines.md`.
- `memory_wait = 6` is fitted: the smallest number of wait states with which the test in the
  board's ROM passes. There are no measurements of a real board, so the speed of programs on the
  board is an estimate.
- There is no K1810VM87 coprocessor, its instructions are skipped.
- The floppy images of emulator versions 1.2 and 1.3 (`004`) do not install as they are:
  «Прикладная программа не установлена». These floppies are copy protected with deleted-mark
  sectors, and a `.dsk` file keeps no marks. The versions themselves work: from repaired copies
  both booted MS-DOS 3.30.
