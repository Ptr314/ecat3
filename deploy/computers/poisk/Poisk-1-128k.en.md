# Poisk-1 (128 KB)

The Poisk-1 with 128 KB of RAM on the board. The top 32 KB (18000-1FFFF) are taken by the
video memory, which is seen only through the B8000 window, so programs get 96 KB:
the BIOS and programs from cassette work, MS-DOS 5.0 does not (it needs about
256 KB). For DOS use the main version with 512 KB or a memory cartridge.
