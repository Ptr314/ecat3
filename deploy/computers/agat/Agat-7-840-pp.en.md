# Agat-7 with a palette card

The standard version: 32 KB of memory on the main board, 32 KB of pseudo-ROM in slot 2 and 32 KB of additional RAM in slot 4. Slot 3 &mdash; the 840 KB floppy drive controller.

Slot 1 holds the [colour palette and loadable character generator card](https://agatcomp.ru/agat/Hardware/Chargen1.shtml).

In this configuration the video output can be switched between the standard RGB and the output of the palette card.

For information about the computer see the description of the main configuration.
