# Agat-9

The standard version, with 128 KB of memory on the main board and an 840 KB floppy drive.

## Using the computer

In the default configuration the computer boots into the IKP package, which holds a minimal set of programs from the standard delivery. When the start screen has loaded, choose a program with the arrows and press Enter.

* More about the package &ndash; on the [agatcomp.ru](http://agatcomp.ru/agat/Software/Other/IKP.shtml) server

## Keyboard:
Special keys:

* РУС/ЛАТ (Russian/Latin): Caps Lock.
* РЕД (edit): Esc or Scroll Lock.
* УПР (control): Ctrl.
* РЕГ (shift): Shift.
* ВК (carriage return): Enter.
* Arrows: the usual arrow keys; BackSpace also works as the left arrow.
* Function keys: F1&ndash;F3.
* Right-hand block (функц (function) 1&ndash;9, 0, &laquo;.&raquo;, &laquo;=&raquo;): the PC numeric keypad with Num Lock on, by key position, not by the labels. On the Agat the top row of the block is 1 2 3, on a PC it is 7 8 9, so the PC's 7 8 9 are функц 1 2 3, its 1 2 3 are функц 7 8 9, 0 and &laquo;.&raquo; are функц 0 and функц &laquo;.&raquo;, and &laquo;+&raquo; is функц &laquo;=&raquo;. This way games controlled with this block are controlled with it here too. The keys of the block are not digits: each has its own code ($90&ndash;$94, $9C&ndash;$9F, $81&ndash;$83); the digits come from the main row. Without a numeric keypad the &laquo;Settings / Keyboard&raquo; item replaces it (arrows or the letters U I O / J K L / M , .), also by position: the up arrow is функц 2, U is функц 1.
* Alphanumeric and symbol keys match a standard QWERTY keyboard in the English layout.
* Ctrl-Break &ndash; reset (УПР-СБРОС), Ctrl-Alt-Break &ndash; cold restart.
* The on-screen keyboard is available.

## File support

The 840 KB drive takes DSK and AIM images.
