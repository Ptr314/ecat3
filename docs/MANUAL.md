## Установка программы

### Онлайн-версия
* Ничего устанавливать не нужно, откройте в браузере адрес https://ecat.emuverse.ru

### Windows
* Скачайте архив из раздела [Releases](../../../releases). Для Windows XP и 7 используйте 32-битный файл с индексом `i386`, для Windows 10+ &mdash; 64-разрядный `x86_64`.
* Для Windows XP и 7 доступны варианты с аппаратным выводом видео `SDL2` (предпочтительный) и программный `Qt` (сильнее нагружает процессор). 
* Для Windows 10+ доступны варианты `opengl` (аппаратный, предпочтительный) и `Qt` (программный).
* Распакуйте архив и запустите ecat3.exe.

### macOS

* Скачайте файл dmg из раздела [Releases](../../../releases). Доступны два варианта вывода видео &mdash; `Qt` (программный, сильнее грузит процессор), `opengl` (аппаратный, предпочтительный).  
* Откройте dmg-файл. Он подключится как диск `eCat3`, на котором лежат программа `eCat3`, ярлык папки &laquo;Программы&raquo; (`Applications`) и папка `software` с образами дисков, лент и программ для всех машин.
* Перетащите значок `eCat3` на ярлык `Applications`, после этого программу можно запускать из Launchpad или папки &laquo;Программы&raquo;. Запустить её можно и прямо с диска, но после его отключения программа будет недоступна.
* Скопируйте папку `software` в удобное место, например в &laquo;Документы&raquo;. Диск dmg доступен только для чтения, поэтому изменения в образах с него не сохраняются, а после отключения диска его файлы пропадают из окна открытия файлов.

### Linux

* Скачайте файл `ecat-4.X.X-linux-x86_64-XXX.AppImage` из раздела [Releases](../../../releases),
* Доступны варианты вывода видео `Qt` (программный, сильнее грузит процессор), `opengl` (аппаратный, предпочтительный).
* Сделайте файл исполняемым (`chmod +x ecat-*.AppImage` или флажок &laquo;Разрешить выполнение&raquo; в свойствах файла) и запустите.
* Для запуска AppImage нужна библиотека FUSE 2. Если при запуске появляется ошибка о FUSE, установите пакет `libfuse2` (в Ubuntu 24.04 &mdash; `libfuse2t64`) или запускайте файл с ключом `--appimage-extract-and-run`.
* AppImage &ndash; это сжатый образ, доступный только для чтения. Образы дисков, лент и программ для всех машин лежат внутри него, и окно открытия файлов в первый раз показывает именно их. Образ подключается во временную папку с каждый раз новым именем, поэтому в следующий запуск эмулятор уже не найдет эту папку, а изменения в образах оттуда не сохраняются.
* Чтобы работать с файлами было удобно, распакуйте AppImage: `./ecat-*.AppImage --appimage-extract`. Появится папка `squashfs-root`, программа запускается файлом `squashfs-root/AppRun`, а образы лежат в `squashfs-root/usr/share/ecat/software`. Эту папку можно скопировать в удобное место, например в `~/Documents`.
* Настройки хранятся в файле `~/.config/ecat.ini`.

## Основные операции

### Выбор компьютера

<p align="center">
<img src="../screenshots/choose_machine.png" width="600">
</p>

* Вариант 1: с помощью кнопки <img src="../src/resources/icons/tv.png" width="30"> на панели главного окна.
* Вариант 2: С помощью пункта меню __&laquo;Файл/Выбор компьютера...&raquo;__.

Если перед нажатием __&laquo;ОК&raquo;__ отметить флажок __&laquo;Установить по умолчанию&raquo;__, данная машина будет открываться по умолчанию при следующем запуске эмулятора.

Кнопка-переключатель <img src="../src/resources/icons/kcmsystem.png" width="30"> __&laquo;Показывать отладочные конфигурации&raquo;__ добавляет в список тестовые конфигурации, у которых параметр __debug__ установлен в 1.

### Свои варианты машин

Вариант машины можно сделать, не трогая ее основную конфигурацию: он хранится в файле __.ext__ (расширение конфигурации) как список отличий от базы &ndash; другой образ диска, цветность экрана, что вставлено в разъем, сценарий, выполняемый после запуска. Формат расширений описан в [CONFIG.md](CONFIG.md#расширения-конфигураций-ext).

Над списком в окне выбора компьютера расположены кнопки:

* <img src="../src/resources/icons/kpager.png" width="30"> __&laquo;Копировать в новую конфигурацию&raquo;__ &ndash; создает новый вариант на основе выбранной машины и сразу открывает его в редакторе. К названию добавляется номер &laquo; (n)&raquo;;
* <img src="../src/resources/icons/package_editors.png" width="30"> __&laquo;Редактировать конфигурацию&raquo;__ &ndash; открывает выбранный вариант (файл __.ext__) в редакторе;
* <img src="../src/resources/icons/trashcan_full.png" width="30"> __&laquo;Удалить конфигурацию&raquo;__ &ndash; удаляет файл варианта (__.ext__ или __.ext.zip__) после подтверждения;
* <img src="../src/resources/icons/package_games_board.png" width="30"> __&laquo;Пользовательские конфигурации&raquo;__ &ndash; переключатель списка: отжатый показывает машины из поставки (каталог __computers__), нажатый &ndash; варианты из каталога пользователя (__ecat-exts__ рядом с программой в Windows, `~/ecat-exts` в Linux и macOS). Положение переключателя запоминается. Вариант пользователя, который не загружается, показывается серым в группе &laquo;Конфигурации с ошибками&raquo;, причина видна во всплывающей подсказке.

Основные конфигурации (__.cfg__) не редактируются и не удаляются, их можно только скопировать. Варианты, входящие в поставку, помечены как защищенные: для них кнопки &laquo;Редактировать&raquo; и &laquo;Удалить&raquo; недоступны, а копирование разрешено, и копия уже принадлежит пользователю. Упакованный вариант (__.ext.zip__) можно только удалить.

Редактор конфигурации показывает таблицу:

* __База__ &ndash; основная конфигурация, от которой отсчитываются изменения (не меняется);
* __Имя файла__ &ndash; заполняется при первом сохранении;
* __Версия__ &ndash; название варианта, под которым он виден в списке машин;
* параметры устройств, которые можно менять: образы дисков и винчестера, образы картриджей, цветность экрана, устройство в разъеме, последовательный порт и т.&nbsp;п. У поля файла есть кнопки выбора и очистки и флажок __&laquo;Вложить&raquo;__, который сохраняет сам файл внутри конфигурации, а не ссылку на него.

Под таблицей &ndash; текст сценария, выполняемого после загрузки машины (см. [SCRIPTING.md](SCRIPTING.md)); пустое поле означает, что сценария нет.

Кнопка __&laquo;Сохранить&raquo;__ записывает файл. При первом сохранении программа спрашивает, куда его положить: рядом с базовой конфигурацией или в каталог пользователя. Кнопка __&laquo;Запустить&raquo;__ загружает вариант в эмулятор так же, как __&laquo;ОК&raquo;__ в окне выбора, предварительно предложив сохранить изменения.

Файл __.cfg__, __.ext__ или __.ext.zip__ можно открыть и пунктом __&laquo;Файл/Открыть файл...&raquo;__: он загружается как машина.

### Перезагрузка и останов

* Холодный перезапуск (с очисткой памяти) с помощью кнопки <img src="../src/resources/icons/power.png" width="30"> или соответствующего пункта меню &laquo;Эмуляция&raquo;.
* Теплый перезапуск (без очистки памяти) с помощью кнопки <img src="../src/resources/icons/reload.png" width="30"> или соответствующего пункта меню &laquo;Эмуляция&raquo;.
* Останов/запуск с помощью кнопок <img src="../src/resources/icons/player_pause.png" width="30"> и <img src="../src/resources/icons/player_play.png" width="30">.

### Экранная клавиатура

Кнопка <img src="../src/resources/icons/keyboard.png" width="30"> на панели и пункт &laquo;Эмуляция / Клавиатура&raquo; открывают окно с рисунком клавиатуры целевой машины. Оно появляется только у машин, для которых такой рисунок подготовлен.

Клавиши-защелки (РУС и ЛАТ, ЗАГЛ и СТР у БК) подсвечиваются автоматически. 
Клавиши-модификаторы, которые на настоящей машине держат нажатыми 
(нижний регистр, СУ и т. д.), залипают по щелчку и отпускаются повторным.

### Запись действий

Действия пользователя можно записать в сценарий (файл __.ecat__, см. [SCRIPTING.md](SCRIPTING.md)) и воспроизвести. Кнопки находятся в правой части панели инструментов и продублированы в меню &laquo;Эмуляция / Запись действий&raquo; (блок кнопок можно скрыть флажком &laquo;Настройки / Панель записи&raquo;, пункты меню при этом продолжают работать):

* <img src="../src/resources/icons/folder_yellow_open.png" width="30"> &ndash; открыть запись из файла;
* <img src="../src/resources/icons/3floppy_unmount.png" width="30"> &ndash; сохранить запись в файл;
* <img src="../src/resources/icons/krec.png" width="30"> &ndash; начать запись (повторное нажатие приостанавливает ее);
* <img src="../src/resources/icons/player_play.png" width="30"> &ndash; воспроизвести запись (повторное нажатие приостанавливает);
* <img src="../src/resources/icons/player_start.png" width="30"> &ndash; перемотать в начало;
* <img src="../src/resources/icons/player_stop.png" width="30"> &ndash; остановить запись или воспроизведение.

Записываются нажатия клавиш, перезапуск, переключение параметров устройств на панели, операции с образами дисков, снимки экрана и управление магнитофоном. Время между событиями отсчитывается по тактам процессора, поэтому запись воспроизводится одинаково на любом компьютере. В строке состояния показывается положение и длительность записи.

### Сохранение состояния

Работающую машину можно сохранить целиком и потом продолжить с того же места: кнопка <img src="../src/resources/icons/mplayer.png" width="30"> на панели или пункт меню __&laquo;Файл/Сохранить состояние...&raquo;__. Программа предлагает имя из имени файла конфигурации, даты и времени.

В окне сохранения можно выбрать одну из двух форм:

* __.ecats.zip__ (&laquo;Сохраненные состояния&raquo;, по умолчанию) &ndash; один архив;
* __.ecats__ (&laquo;Сохраненные состояния, без упаковки&raquo;) &ndash; текстовый файл и рядом с ним каталог `<имя>.files/` с остальными файлами. Эта форма удобна, чтобы посмотреть или поправить содержимое вручную.

Снимок самодостаточен: в нем лежит конфигурация машины, все файлы, от которых она зависит (ПЗУ, раскладки клавиатуры, рисунки), и образы дисков, винчестера и ленты вместе со всем, что машина успела на них записать. Поэтому он открывается и на другом компьютере, и после того, как исходные образы изменились.

Открывается снимок как любая машина: пунктом __&laquo;Файл/Открыть файл...&raquo;__ (фильтр &laquo;Сохраненные состояния&raquo;), из командной строки, командой __MACHINE__ сценария, а в онлайн-версии &ndash; кнопкой открытия файла или по ссылке `index.html?load=<адрес снимка>`. В списке окна выбора компьютера снимки не показываются.

Восстанавливается все, что относится к самой машине: регистры процессора, память, состояние устройств, положение головок и ленты, параметры устройств с панели (цветность экрана, что вставлено в разъем). Программа, ждавшая нажатия клавиши, продолжит его ждать.

Не восстанавливается то, что относится к компьютеру, на котором работает эмулятор, и к сеансу отладки:

* клавиши, которые были нажаты в момент сохранения, и движение мыши &ndash; после открытия снимка все клавиши отпущены;
* точки останова и режим отладчика &ndash; снимок открывается работающим, а не остановленным;
* буфер звука.

Подробности формата &ndash; в [CONFIG.md](CONFIG.md#сохраненное-состояние-ecats).

## Работа с файлами

### Прямая загрузка в память

Результат будет отличаться в зависимости от выбранного компьютера. В общем случае файл будет напрямую загружен в память, минуя все программные механизмы эмулируемого компьютера.

Подробности смотрите в описании компьютера при его [выборе в соответствующем окне](#выбор-компьютера).

* Вариант 1: с помощью кнопки <img src="../src/resources/icons/cdrom_mount.png" width="30"> на панели главного окна.
* Вариант 2: С помощью пункта меню __&laquo;Файл/Открыть файл...&raquo;__.

### Дисководы

<p align="center">
<img src="../screenshots/fdd_menu.png" width="400">
</p>

Если в конфигурации компьютера есть дисководы, то в панели управления появляется одна или несколько кнопок <img src="../src/resources/icons/5floppy_mount.png" width="30">. У каждой кнопки есть дополнительное меню, с помощью которого можно посмотреть, какой образ загружен, загрузить другой файл, сохранить измененный образ на диск. 

Нажатие на саму иконку позволяет быстро выбрать образ, не открывая меню.

В моменты обращения компьютера к диску стрелка на иконке становится красной: <img src="../src/resources/icons/5floppy_access.png" width="30">

Примечание: возможность сохранения образа в различные форматы зависит от выбранного компьютера. 

### Загрузка с магнитофона

<p align="center">
<img src="../screenshots/Electronica-302.png" width="600"><br/>
<small>Автор изображения &ndash; <a href="http://www.mcclaud.ru">McClaud</a></small>
</p>

Иконка магнитофона появляется в панели, если магнитофон есть в конфигурации компьютера.

1. Открыть окно эмулятора магнитофона кнопкой <img src="../src/resources/icons/kdat.png" width="30"> в главном окне программы;
2. Открыть файл кнопкой &laquo;СТОП/ВЫБРОС&raquo; (самая правая с синим индикатором);
3. Запустить воспроизведение кнопкой &laquo;ПУСК&raquo;;
4. Действия в эмулируемой системе описаны в документации к конкретной машине.
5. Другие действия:
    * Кнопка &laquo;ОСТАНОВ&raquo; &ndash; пауза;
    * Кнопка &laquo;СТОП/ВЫБРОС&raquo; &ndash; при воспроизведении &ndash; остановка, второе нажатие &ndash; открыть файл;
    * Кнопка &laquo;ПЕРЕМОТКА ВЛЕВО&raquo; &ndash; сброс текущей позиции файла на начало.
    * Регулятор &laquo;ГРОМКОСТЬ&raquo; &ndash; заглушить звук.

У некоторых машин лентопротяжкой управляет сама машина, и кнопки в окне нажимать не нужно:

* __Юниор__ и __Арго__ &ndash; магнитофон с дистанционным управлением: команды монитора и TCP/M сами запускают, останавливают, перематывают ленту и включают запись. Окно магнитофона при этом только показывает, что происходит (нажатые кнопки, вращение роликов), и его можно вообще не открывать. В режиме ZX Spectrum у Арго лентой управляют стрелки клавиатуры, подробнее &ndash; в описании машины.
* __Ириша__ и родственные ей машины включают и выключают двигатель магнитофона сами: заряженная лента идет, пока программа ее читает.

Если лентой управляет машина, закрытие окна магнитофона ее не останавливает.

### Запись на магнитофон

1. Открыть окно магнитофона;
2. Нажать кнопку &laquo;ЗАПИСЬ&raquo; (самая левая) до того, как машина начнет запись;
3. Дать команду записи в эмулируемой системе;
4. Когда машина закончит, отжать кнопку &laquo;ЗАПИСЬ&raquo;: эмулятор предложит сохранить записанное в файл. Имя и расширение, если их удалось распознать в сигнале, предлагаются автоматически.

Если машина писала на ленту, а в окне нажата кнопка &laquo;СТОП/ВЫБРОС&raquo; для смены кассеты, эмулятор сначала спросит, не сохранить ли записанное.

Юниору и Арго (кроме режима ZX Spectrum) нажимать &laquo;ЗАПИСЬ&raquo; не нужно: машина включает запись сама. Сохраняется в этом случае вся кассета (файл __.bt__), и предложение сохранить ее появляется при смене кассеты.

## Средства отладки

### Состояние устройств
<p align="center">
<img src="../screenshots/menu_devices.png" width="600">
</p>

Все доступные устройства перечислены в меню &laquo;Эмуляция/Устройства&raquo;. Те устройства, для которых доступно отладочное окно, выводятся черным цветом. Если отладочное окно недоступно &ndash; серым.

Отладочное окно процессора является одновременно основным отладчиком в системе.

### Основной отладчик

<p align="center">
<img src="../screenshots/debug_z80.png" width="600"><br/>
<small>Окно отладчика для процессора Z80</small>
</p>

Основной отладчик может быть вызван тремя способами:

1. С помощью кнопки <img src="../src/resources/icons/terminal.png" width="30"> на панели главного окна.
2. С помощью пункта меню __&laquo;Эмуляция/Отладчик&raquo;__.
3. Через меню &laquo;Эмуляция/Устройства&raquo;, если открыть окно отладки устройства CPU.

Окно отладчика содержит следующие элементы:

* Панель состояния с кнопками управления;
* Панель дизассемблера;
* Две панели состояния регистров и флагов процессора;
* Панель дампа памяти (так, как память видит сам процессор с учетом диспетчера).

#### Панель состояния

Верхняя панель состоит из четырех блоков:

* Символ режима работы процессора:
    * <img src="../src/resources/icons/player_play.png" width="20"> &ndash; процессор запущен без отладки;
    * <img src="../src/resources/icons/player_pause.png" width="20"> &ndash; процессор остановлен;
    * <img src="../src/resources/icons/debug.png" width="20"> &ndash; процессор запущен под отладчиком, отслеживаются точки останова и состояние регистров;
    
* Блок управления выполнением:
    * <img src="../src/resources/icons/undo.png" width="20"> &ndash; возврат курсора панели дизассемблера на текущую точку исполнения;
    * <img src="../src/resources/icons/forward.png" width="20"> &ndash; шаг внутрь (с заходом в подпрограмму), короткая клавиша F7;
    * <img src="../src/resources/icons/step_over.png" width="20"> &ndash; шаг поверх (без захода в подпрограмму), короткая клавиша F8;
    * <img src="../src/resources/icons/finish.png" width="20"> &ndash; выполнить до курсора, короткая клавиша F4;
    * <img src="../src/resources/icons/player_play.png" width="20"> &ndash; запустить под отладчиком (с отслеживанием точек останова), короткая клавиша F9;
    * <img src="../src/resources/icons/player_pause.png" width="20"> &ndash; останов процессора;
    * <img src="../src/resources/icons/player_fwd.png" width="20"> &ndash; запуск без отладки.
    
* Блок управления панелью дизассемблера:
    * Строка ввода адреса или значения регистра; 
    * <img src="../src/resources/icons/next.png" width="20"> &ndash; переключение панели дизассемблера на введенный адрес (установка курсора);
    * <img src="../src/resources/icons/edit_add.png" width="20"> &ndash; установка точки останова на адрес под курсором. (Для установки точки сначала необходимо нажать кнопку установки курсора на нужный адрес!);
    * <img src="../src/resources/icons/edit_remove.png" width="20"> &ndash; удаление точки останова с адреса под курсором. (Курсор должен стоять на нужном адресе!);
    * Выпадающий список с именами регистров;
    * <img src="../src/resources/icons/button_accept.png" width="20"> &ndash; запись значения в выбранный регистр.

* Блок управления панелью дампа памяти:
    * Строка ввода адреса;
    * <img src="../src/resources/icons/next.png" width="20"> &ndash; переключение панели дампа на введенный адрес;
    * <img src="../src/resources/icons/2downarrow.png" width="20"> &ndash; переход на страницу вниз;
    * <img src="../src/resources/icons/2uparrow.png" width="20"> &ndash; переход на страницу вверх.

Примечание: для того, чтобы иметь возможность настроить отладчик и другие окна до запуска эмулируемой машины, можно использовать параметр процессора stopped=1 в конфигурации машины (подробнее см. в [документации по настройке](CONFIG.md)).
