# Elektronika MS 0585 (Elektronika-85)

A Soviet personal computer, the counterpart of the DEC Professional 350: a KM1811VM1
(F-11) processor with a floating point unit, 512 KB of RAM, the NV1 video controller
with the NV2 expansion (1024 x 256 pixels, 8 colours out of 256), a floppy controller
built around an 8751 microcontroller, and the MS7004 keyboard.

After power-on the ROM self test checks the machine and shows the word «ЭЛЕКТРОНИКА»,
then a floppy icon with a question mark. If the test finds a fault, the screen shows
a picture of the system unit with the slot number, the error code and the device code.
The test takes about 20 seconds, as on the real machine.

## Booting

Put `software/e85/pros-d-1.8-system.dsk` into drive 0: the PROS(D) 1.8 operating
system loads. PROS is the Soviet P/OS. The full PROS 2.03 runs from a hard disk, which
is a separate configuration, «МС 0585 с винчестером».

## Sound

The only sound source is the piezo buzzer in the keyboard: two short beeps at power-on,
and a click on every auto-repeat of a held key. A plain key press does not click: this
is what the keyboard's firmware does. Some games click on their own, «Лабиринт» and
«Вертолет» among them. The bell is off in PROS. To turn it on, open the setup menu with
Scroll Lock, go to «Звонок включен» with the arrows, press Select (End), and leave with
Resume.

## Floppies

The images are in `software/e85`, 400 KB each, 80 tracks of 10 sectors:

| File | Contents |
|---|---|
| `pros-d-1.8-system.dsk` | PROS(D) 1.8, the system |
| `tpo-1.dsk`, `tpo-2.dsk` | test programs (the «Техническое обслуживание» menu) |
| `pros-2.03-1-system.dsk` ... `pros-2.03-5-utilit.dsk` | installation of PROS 2.03 on a hard disk |
| `eldos-msdos-3.30.dsk`, `eldos-msdos-utils.dsk`, `eldos-chi-dos-3.30.dsk`, `eldos-emulator.dsk` | DOS for MS 1702 and the emulator's installation, see [MS0585-1702.en.md](../../deploy/computers/e85/MS0585-1702.en.md) |
| `igra.dsk`, `igra-color.dsk` | games for NV1 and for a colour monitor with NV2, installed on the hard disk from PROS 2.03 |
| `rt11-sj.dsk` | RT-11 SJ, does not boot with this ROM: its loader expects another one |
| `emul-1.3.hfe` | «Эмулятор DOS v 1.3» for the MS 1702 board, a floppy with deleted-mark sectors |
| `format-2.0.dsk` | «Форматирование дискет v 2.0», installed on the hard disk. It formats floppies only on the firmware «КОЧАН, форматирующая», chosen in the configuration editor: on the standard one the program reports success but formats nothing |
| `start-1.dsk` ... `start-5.dsk` | the СТАРТ package: a window environment and its programs, installed on the hard disk. The installation asks for the second floppy in drive 2. The environment and the start of «Электронный лист» were checked |

After loading, PROS(D) asks for a floppy with an application. To run the tests, put
`tpo-1.dsk` into drive 0 and press Resume. When the second floppy is requested, put
`tpo-2.dsk` into drive 1 and press Resume again. In the menu, choose with the arrows,
start with Do and go back with Exit.

## Keys

| PC key | MS7004 |
|---|---|
| F1-F4 | ПФ1-ПФ4 (PF1-PF4) |
| F5 | ДОП ВАРИАНТ (Addtnl Options) |
| F6, F7, F8 | ПРЕРЫВ, ПРОДОЛЖ, ОТМЕН (Interrupt, Resume, Cancel) |
| F9, F10 | ОСНОВН КАДР, ВЫХОД (Main Screen, Exit) |
| F11, F12 | ПМ, ИСП (Help, Do) |
| Home, Insert, Delete | НТ, ВСТ, УДАЛ (Find, Insert Here, Remove) |
| End | ВЫБР (Select) |
| Page Up, Page Down | ПРЕД КАДР, СЛЕД КАДР (Prev Screen, Next Screen) |
| Scroll Lock | УСТ РЕЖИМА (Set-Up) |
| numeric keypad with Num Lock on | numeric keypad of the MS7004 |

The other keys of the MS7004, such as СТОП КАДР and ПАУЗА, are on the on-screen keyboard:
the keyboard button on the toolbar.
