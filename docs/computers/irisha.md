# Ириша и клоны

Учебный компьютер на КР580ВМ80А и его клоны. Группа «Ириша» в окне выбора машины.

## Конфигурации

| Конфигурация | Состав | Описание |
|---|---|---|
| Ириша (ГМД70) | Вариант журнала «Микропроцессорные средства и системы»: 64+64 КБ ОЗУ, расширение ПЗУ (игры, редактор), магнитофон, дисковод 8" ГМД7012 | [Irisha-gmd70.md](../../deploy/computers/irisha/Irisha-gmd70.md) |
| Ириша (КНГМД) | «Ириша-М» с модулем RTV*001.89: КР1818ВГ93, BIOS 4U, CP/M, дисководы 5,25" A:, B:, RAM-диск D:, дисководы 8" E:, F: | [Irisha-kngmd.md](../../deploy/computers/irisha/Irisha-kngmd.md) |
| Диалог | Клон с собственной прошивкой (20 КБ ПЗУ: меню, редактор IRITEXT, отладчик DDT), без дополнительного ОЗУ | [Dialog.md](../../deploy/computers/irisha/Dialog.md) |
| Каспий | Клон с собственной прошивкой; отладчик восстановлен по прошивке Ириши | [Kaspiy.md](../../deploy/computers/irisha/Kaspiy.md) |

## Что нужно

ПЗУ входят в поставку: `deploy/computers/irisha/`. Диски &ndash; в `software/irisha` (`disk5.gmd` &ndash; игры, `02.cpm` &ndash; утилиты CP/M).

## Файлы

| Носитель | Формат |
|---|---|
| Дисковод 8" ГМД7012 | `.gmd`, 256 КБ |
| Дисковод 5,25" (КНГМД) | 360 КБ: `.cpm` (по сторонам), `.dsk` (по цилиндрам); порядок дорожек по расширению |
| Магнитофон | `.bin` (данные без заголовков) |

## Ограничения

* Каспий: сетевое подключение к дисководу через УС-10 не эмулируется.
