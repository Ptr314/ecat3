# Электроника БК

[Русский](bk.md) | [English](bk.en.md)

Домашни компютри с К1801ВМ1 (система команди PDP-11). Група «БК» в прозореца за избор на машина. Числата в конфигурациите и сценариите са осмични.

## Конфигурации

| Конфигурация | Състав | Описание |
|---|---|---|
| БК0010 (Фокал) | 3 MHz, 16+16 КБ ОЗУ, Монитор, Фокал, тестове; мембранна клавиатура | [BK-0010.bg.md](../../deploy/computers/bk/BK-0010.bg.md) |
| БК0010-01 (Бейсик) | 3 MHz, 16+16 КБ ОЗУ, Монитор, Бейсик «Вильнюс» | [BK-0010-01.bg.md](../../deploy/computers/bk/BK-0010-01.bg.md) |
| БК0010-01 + КНГМД | Контролер К1801ВП1-128, ПЗУ DISK 326, 16 КБ ОЗУ вместо Бейсик; ANDOS 3.30 | [BK-0010-01-fdd.bg.md](../../deploy/computers/bk/BK-0010-01-fdd.bg.md) |
| БК0010-01 + А16М | Контролер А16М (АльтПро): флопидисково устройство, ПЗУ v2.44, 16 КБ ОЗУ | [BK-0010-01-a16m.bg.md](../../deploy/computers/bk/BK-0010-01-a16m.bg.md) |
| БК0010-01 + СМК-512 | Платка СМК-512 (FPGA реплика): 512 КБ, BIOS v2.05, флопидисково устройство, твърд диск IDE | [BK-0010-01-smk512.bg.md](../../deploy/computers/bk/BK-0010-01-smk512.bg.md) |
| БК0011М (Бейсик) | 4 MHz, 128 КБ ОЗУ на страници, БОС, Бейсик, 16 палитри, кадрово прекъсване | [BK-0011M.bg.md](../../deploy/computers/bk/BK-0011M.bg.md) |
| БК0011М + КНГМД | Флопидискови устройства, ANDOS 3.30 | [BK-0011M-fdd.bg.md](../../deploy/computers/bk/BK-0011M-fdd.bg.md) |
| БК0011М + А16М | Контролер А16М, достъп до пултовия режим | [BK-0011M-a16m.bg.md](../../deploy/computers/bk/BK-0011M-a16m.bg.md) |
| БК0011М + СМК-512 | Платка СМК-512 | [BK-0011M-smk512.bg.md](../../deploy/computers/bk/BK-0011M-smk512.bg.md) |
| БК0011М + МСТД | Модул за тестова диагностика, стартиране в менюто с тестове | [BK-0011M-mstd.bg.md](../../deploy/computers/bk/BK-0011M-mstd.bg.md) |

Конфигурации за дебъгване: «Тест К1801ВМ1», «Тест двух процессоров».

Избор на лентата с инструменти:
* Звукова приставка на порт 0177714: AY-3-8910, 2xAY (TurboSound, GryphonSound) или Covox.
* Съединител УП: джойстик, мишка УВК-01 «Марсианка», принтер или празен.
* Режим на екрана: цветен, «Ч/Б», «Моно». Менюто «Екран / Висока точност» &ndash; рисуване на реда след лъча.

## Какво е необходимо

ПЗУ са включени в комплекта: `deploy/computers/bk/files/`. Дискета ANDOS 3.30 &ndash; `software/bk/andos330.img`. Образ на твърд диск за СМК-512 не е включен в комплекта.

## Файлове

| Носител | Формат |
|---|---|
| Програми | `.bin` със заглавна част с адреса за зареждане, «Файл / Отвори файл» |
| Магнетофон | `.bin`, `.cod`, `.foc`, `.asc` (текст на Бейсик) |
| Дискети | `.img`, `.bkd`, `.dsk` (819200 байта; допускат се 40 писти), `.hfe`. Запис &ndash; в паметта, съхраняване ръчно |
| Твърд диск (СМК-512) | `.img`, `.hdi`; запис направо във файла |

## Клавиатура

РУС/ЛАТ &ndash; Caps Lock, АР2 &ndash; Alt, СУ &ndash; Ctrl, СБР &ndash; Home. Регистърът на буквите се задава от фиксиращите клавиши ЗАГЛ и СТР. Джойстик: стрелките, End, Home, PgUp, PgDn.
