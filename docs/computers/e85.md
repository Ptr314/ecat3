# Электроника МС 0585 (Электроника-85)

Персональная ЭВМ, советский аналог DEC Professional 350: процессор КМ1811ВМ1 (F-11)
с адаптером плавающей запятой, 512 КБ ОЗУ, видеоконтроллер НВ1 с расширителем
НВ2 (1024 x 256 точек, 8 цветов из 256), контроллер дисковода на микроЭВМ 8751,
клавиатура МС7004.

После включения автотест ПЗУ проверяет машину и выводит надпись «ЭЛЕКТРОНИКА», затем
значок дискеты с вопросом. Если автотест нашёл неисправность, на экране рисунок
системного блока, номер позиции, код ошибки и код устройства. Проверка занимает
около 20 секунд, как на настоящей машине.

## Загрузка

Вставьте в привод 0 дискету `software/e85/pros-d-1.8-system.dsk`: загрузится
операционная система ПРОС(Д) 1.8. Полная система ПРОС 2.03 работает с винчестера,
это отдельная конфигурация «МС 0585 с винчестером».

## Звук

Единственный источник звука - пьезозвонок в клавиатуре: при включении машины звучат
два коротких сигнала, удерживаемая клавиша щёлкает на каждом автоповторе. Обычное
нажатие не щёлкает: так в прошивке клавиатуры. Некоторые игры щёлкают сами, например
Лабиринт и Вертолет. Звонок в ПРОС выключен, включается в меню установки режимов:
Scroll Lock, стрелками на «Звонок включен», ВЫБР (End), выход - ПРОДОЛЖ.

## Дискеты

Образы в `software/e85`, все по 400 КБ, 80 дорожек по 10 секторов:

| Файл | Содержимое |
|---|---|
| `pros-d-1.8-system.dsk` | ПРОС(Д) 1.8, система |
| `tpo-1.dsk`, `tpo-2.dsk` | тестовые программы (меню «Техническое обслуживание») |
| `pros-2.03-1-system.dsk` ... `pros-2.03-5-utilit.dsk` | установка ПРОС 2.03 на винчестер |
| `eldos-msdos-3.30.dsk`, `eldos-msdos-utils.dsk`, `eldos-chi-dos-3.30.dsk`, `eldos-emulator.dsk` | DOS для МС 1702 и установка эмулятора, см. [MS0585-1702.md](../../deploy/computers/e85/MS0585-1702.md) |
| `igra.dsk`, `igra-color.dsk` | игры для НВ1 и для цветного монитора с НВ2, ставятся на винчестер из ПРОС 2.03 |
| `rt11-sj.dsk` | RT-11 SJ, с этим ПЗУ не загружается: загрузчик рассчитан на другое ПЗУ |

После загрузки ПРОС(Д) просит вставить дискету с прикладной программой. Чтобы
запустить тесты, вставьте в привод 0 `tpo-1.dsk` и нажмите ПРОДОЛЖ, а на запрос
второй дискеты вставьте `tpo-2.dsk` в привод 1 и снова нажмите ПРОДОЛЖ. В меню
выбирайте стрелками, запуск - ИСП, возврат - ВЫХОД.

## Клавиши

| Клавиша ПК | МС7004 |
|---|---|
| F1-F4 | ПФ1-ПФ4 |
| F5 | ДОП ВАРИАНТ |
| F6, F7, F8 | ПРЕРЫВ, ПРОДОЛЖ, ОТМЕН |
| F9, F10 | ОСНОВН КАДР, ВЫХОД |
| F11, F12 | ПМ, ИСП |
| Home, Insert, Delete | НТ, ВСТ, УДАЛ |
| End | ВЫБР |
| Page Up, Page Down | ПРЕД КАДР, СЛЕД КАДР |
| Scroll Lock | УСТ РЕЖИМА |
| цифровой блок при включённом Num Lock | цифровой блок МС7004 |

Остальные клавиши МС7004, например СТОП КАДР и ПАУЗА, нажимаются на экранной клавиатуре:
кнопка с клавиатурой на панели инструментов.

## Что ещё не работает

- Сопроцессор МС 1702.
- Связь наружу: коммуникационный порт работает только в петле,
  как при проверке системного блока.
