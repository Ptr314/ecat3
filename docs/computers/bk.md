# Электроника БК

Бытовые компьютеры на К1801ВМ1 (система команд PDP-11). Группа «БК» в окне выбора машины. Числа в конфигурациях и сценариях &ndash; восьмеричные.

## Конфигурации

| Конфигурация | Состав | Описание |
|---|---|---|
| БК0010 (Фокал) | 3 МГц, 16+16 КБ ОЗУ, Монитор, Фокал, тесты; пленочная клавиатура | [BK-0010.md](../../deploy/computers/bk/BK-0010.md) |
| БК0010-01 (Бейсик) | 3 МГц, 16+16 КБ ОЗУ, Монитор, Бейсик «Вильнюс» | [BK-0010-01.md](../../deploy/computers/bk/BK-0010-01.md) |
| БК0010-01 + КНГМД | Контроллер К1801ВП1-128, ПЗУ DISK 326, 16 КБ ОЗУ вместо Бейсика; ANDOS 3.30 | [BK-0010-01-fdd.md](../../deploy/computers/bk/BK-0010-01-fdd.md) |
| БК0010-01 + А16М | Контроллер А16М (АльтПро): дисковод, ПЗУ v2.44, 16 КБ ОЗУ | [BK-0010-01-a16m.md](../../deploy/computers/bk/BK-0010-01-a16m.md) |
| БК0010-01 + СМК-512 | Плата СМК-512 (ПЛИС-реплика): 512 КБ, BIOS v2.05, дисковод, винчестер IDE | [BK-0010-01-smk512.md](../../deploy/computers/bk/BK-0010-01-smk512.md) |
| БК0011М (Бейсик) | 4 МГц, 128 КБ ОЗУ страницами, БОС, Бейсик, 16 палитр, кадровое прерывание | [BK-0011M.md](../../deploy/computers/bk/BK-0011M.md) |
| БК0011М + КНГМД | Дисководы, ANDOS 3.30 | [BK-0011M-fdd.md](../../deploy/computers/bk/BK-0011M-fdd.md) |
| БК0011М + А16М | Контроллер А16М, доступ к пультовому режиму | [BK-0011M-a16m.md](../../deploy/computers/bk/BK-0011M-a16m.md) |
| БК0011М + СМК-512 | Плата СМК-512 | [BK-0011M-smk512.md](../../deploy/computers/bk/BK-0011M-smk512.md) |
| БК0011М + МСТД | Модуль тестовой диагностики, запуск в меню тестов | [BK-0011M-mstd.md](../../deploy/computers/bk/BK-0011M-mstd.md) |

Отладочные конфигурации: «Тест К1801ВМ1», «Тест двух процессоров».

Выбор на панели инструментов:
* Звуковая приставка на порту 0177714: AY-3-8910, 2xAY (TurboSound, GryphonSound) или Covox.
* Разъем УП: джойстик, мышь УВК-01 «Марсианка», принтер или пусто.
* Режим экрана: цветной, «Ч/Б», «Моно». Меню «Экран / Высокая точность» &ndash; рисование строки за лучом.

## Что нужно

ПЗУ входят в поставку: `deploy/computers/bk/files/`. Дискета ANDOS 3.30 &ndash; `software/bk/andos330.img`. Образ винчестера для СМК-512 в поставку не входит.

## Файлы

| Носитель | Формат |
|---|---|
| Программы | `.bin` с заголовком адреса загрузки, «Файл / Открыть» |
| Магнитофон | `.bin`, `.cod`, `.foc`, `.asc` (текст Бейсика) |
| Дискеты | `.img`, `.bkd`, `.dsk` (819200 байт; 40 дорожек допускаются), `.hfe`. Запись &ndash; в памяти, сохранение вручную |
| Винчестер (СМК-512) | `.img`, `.hdi`; запись прямо в файл |

## Клавиатура

РУС/ЛАТ &ndash; Caps Lock, АР2 &ndash; Alt, СУ &ndash; Ctrl, СБР &ndash; Home. Регистр букв задают защелки ЗАГЛ и СТР. Джойстик: стрелки, End, Home, PgUp, PgDn.
