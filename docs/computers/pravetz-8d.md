# Правец-8Д

[Български](pravetz-8d.bg.md) | Правец-82, 8М, 8А, 8С &ndash; [отдельная страница](pravetz.md)

Болгарский домашний компьютер середины 1980-х, аналог Oric Atmos. С Apple-совместимыми моделями Правец не совместим. Группа «Правец» в окне выбора машины, конфигурация «Правец-8Д».

## Конфигурация

| Узел | Состав |
|---|---|
| Процессор | 6502, 1 МГц |
| Память | 64 КБ ОЗУ, 16 КБ ПЗУ (БЕЙСИК Oric с кириллицей) |
| Экран | ULA: текст 40x28, HIRES 240x200 с тремя строками текста, 8 цветов, мерцание, двойная высота |
| Звук | AY-3-8912 |
| Порты | VIA MOS 6522 |
| Магнитофон | CSAVE/CLOAD, мотором управляет машина |
| Дисковод | Контроллер Правец (Disk II на $0310&ndash;$031F, ПЗУ 8DOS), 140 КБ; загрузка `CALL 800` |

## Отличия от Oric Atmos

| | Oric Atmos | Правец-8Д |
|---|---|---|
| ПЗУ | БЕЙСИК Oric 1.1 | БЕЙСИК Oric с кириллицей |
| Клавиатура | латиница | переключатель C/L; болгарский алфавит (Ъ на клавише Y, Ы нет); Ю Ш Э Щ Ч &ndash; Shift с @ [ \ ] ^ |
| Дисковод | Microdisc (3") | контроллер Правец: Disk II на $0310&ndash;$031F, ПЗУ 8DOS (512 байт, окно $0320&ndash;$03FF), диски 5,25" 140 КБ, система 8D RDOS |

Описание: [Pravetz-8D.md](../../deploy/computers/pravetz/Pravetz-8D.md).

## Что нужно

ПЗУ машины и контроллера дисковода входят в поставку: `deploy/computers/pravetz/files/`. В дисководе по умолчанию &ndash; системный диск 8D RDOS 2.31 (`software/pravetz/rdos231-8d.dsk`, пустой каталог; команды `DIR`, `SAVE"ИМЯ"`, `LOAD"ИМЯ"`).

## Файлы

| Носитель | Формат |
|---|---|
| Магнитофон | `.tap` (формат эмуляторов Oric), `.wav`; запись сохраняется в `.tap` |
| Дисковод | образы 140 КБ |

## Клавиатура

* C/L (кириллица/латиница) &ndash; Caps Lock. В кириллице Shift с буквой дает латиницу.
* Ю, Ш, Э, Щ, Ч &ndash; клавиши `` ` ``, `{`, `|`, `}`, `~`.
* Болгарский алфавит: Ъ на клавише Y, буквы Ы нет.
* МК &ndash; Ctrl, ОСВ &ndash; Esc, DEL &ndash; Backspace или Delete.
* RESET &ndash; F12: NMI, теплый старт без потери программы.
* Экранная клавиатура по фотографии машины.
