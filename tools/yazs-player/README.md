# ЯЗС-плеер и «Симфония А-Г-А-Т»

Трекерный плеер для ячейки звукового синтеза 5/2 (ЯЗС) Агата-9, его формат `.YZ`, компилятор
партитур на Python и шесть частей симфонии. Все это собирается на демонстрационный диск
`library/agat/yazs-player.dsk` (и `.hfe` для Gotek/HxC). Диск рассчитан и на eCat3, и на настоящий
Агат-9 с дисководом 840 КБ.

## Диск

Дорожка 0 и ДОС 3.3 взяты с `docs-external/Agat/sound/soundtest.DSK`. Там стоит «Быстропускалка»
V2.0 (Ravodin, 2015). Если на диске ровно один защищенный двоичный файл, она запускает его сама, без
ДОС. Этот файл — `ЯЗС-ПЛЕЕР` (`$1800`). Мелодии лежат рядом как незащищенные двоичные файлы `*.YZ`.
Их можно дописать на диск ИКП, DISK Commander или `fddconv` — плеер найдет все.

| Файл | Длина | Что |
|---|---|---|
| `1.ТОККАТА И ФУГА.YZ` | 2:09 | барокко, ля минор: полный орган, педаль, фуга на 4 голоса |
| `2.АДАЖИО.YZ` | 2:22 | романтизм, фа мажор: виолончель, арфа, хорус скрипок, литавры |
| `3.СКЕРЦО-ВАЛЬС.YZ` | 1:30 | ре мажор, 3/4: флейта с трелями и форшлагами, пиццикато, accelerando |
| `4.БЛЮЗ 1987.YZ` | 1:56 | свинг, си-бемоль: труба с подтяжками, Хаммонд, шагающий бас |
| `5.ЭЛЕКТРИЧЕСКИЙ СОН.YZ` | 2:17 | синтвейв, ми минор: арпеджиатор с «фильтром», эхо, лазеры, чиптюн |
| `6.ФИНАЛ.YZ` | 2:03 | рок -> симфоническая кода, ля минор -> ля мажор |
| `ТУР ПО ТЕМБРАМ.YZ` | 1:26 | что умеет ячейка: по одному приему, с подписями |

Лейтмотив симфонии — криптограмма слова АГАТ: ля (A), соль (G), ля (A), си (Т = «ти»). Он
проходит через все части: в токкате октавами органа, в фуге — темой, в адажио — у виолончели, в вальсе
— у флейты, в блюзе — цитатой в соло органа, в синтвейве — хуком дропа, в финале — в увеличении.

### Управление

- **Меню**: ВВЕРХ/ВНИЗ — выбор, ВВОД или ПРОБЕЛ — играть, А — все подряд (по кругу), Д —
  перечитать каталог (другой диск), ВЛЕВО/ВПРАВО — слот ячейки (1-6, по умолчанию 1), РЕД — в монитор.
- **Во время игры**:
  - ВВОД — вид «пульт» (АЦР-32: инструмент, нота, уровень, полосы НЧ/СЧ/ВЧ и D3 каждого канала,
    регистры и периоды, подписи о приемах) или «трекер» (АЦР-64: строки кадра, вспышка палитры на
    ударах);
  - ВПРАВО — следующий кадр;
  - ПРОБЕЛ — следующая мелодия;
  - РЕД — в меню.

### На настоящей машине

- Ячейка — в слоте 1 (`$C090`), как ее ищет почти весь софт. Автопоиска нет намеренно: чтение
  чужих слотов может сбить их состояние (форум agatcomp, тема 515). Другой слот выбирается в меню.
- Прерывания не используются: SEI все время, такт — опрос флага таймера ячейки и сброс его командой
  защелки `$80` в `+7`. При старте сначала `+F = $C0` и режим 3 всем шести счетчикам: после
  включения ВИ53 стоят в случайных режимах. Перед выходом — тишина и `+F = $C0`.
- Повторный удар ноты или ударного: D4 = 0 на один тик раньше. Без этого плата не дает акцента, а
  ударный не перезапускается. На сброс D4 как на глушение ударного плеер не опирается (модель eCat3
  так не глушит).
- Диск 840 КБ читается своим драйвером (`disk.a65`):
  - поле адреса и данных разбираются так же, как в загрузочном ПЗУ контроллера;
  - шаг головки (5 мс), успокоение (18 мс) и сторона — как у «Быстропускалки»;
  - на поиск синхронизации и раскрутку мотора есть таймауты.
- Память:

  | Адреса | Что |
  |---|---|
  | `$0400-$0FFF` | переменные, буферы, каталог |
  | `$1000-$17FF` | экран |
  | `$1800-$3EFB` | плеер |
  | `$3EFC-$BFFF` | мелодия (до 33 КБ) |

  `$D000+` («Быстропускалка» и монитор) плеер не трогает.

## Сборка

```
python build.py                 диск в library/agat/yazs-player.dsk и .hfe
python build.py --only m2_adagio --disk x.dsk   только эти партитуры
python listen.py m5_synth --mp3 одна часть: диск, WAV и MP3 на скорости MAX, анализ
python verify.py диск.dsk файл.yz 400 97        плеер против модели pyplay.py по тикам
python measure.py out           замер палитры (все сочетания полос, огибающих, D3, ударные)
python spectro.py a.wav 0 30 a.png              спектрограмма с нотной сеткой
```

Движок проверяется на `score/test_fx.py`: все команды и эффекты по разу (`build.py --only none
--extra test_fx`, затем `verify.py`). Правка движка идет сначала в `pyplay.py`, потом в
`engine.a65`. Диск в `library/agat` загружает тест `tests/scripts/work-agat-9-yazs-player.ecat`: после
пересборки диска его эталоны перезаписываются (`run_tests.py --update -k yazs-player --exe ...`).

Нужны Python с numpy (matplotlib — для спектрограмм) и `src/tests/6502/as65/as65.exe` (AS65 1.42,
Win32). `render.py` гоняет `eCat3-headless` (или `ECAT3_EXE`) в своем рабочем каталоге: ссылки на
`deploy/computers`, `data`, `software` и копия `.ecat.ini`, — так что рабочий `deploy/ecat.ini` не
трогается.

| Файл | Что |
|---|---|
| `FORMAT.md` | формат `.YZ` версии 1 |
| `player.a65`, `engine.a65`, `disk.a65`, `ui.a65`, `tracker.a65` | плеер (AS65) |
| `gen_tables.a65`, `gen_const.a65` | генерирует `build.py` (периоды, вибрато, строки) |
| `tables.py` | периоды счетчиков, таблица вибрато, перекодировка текста в коды экрана Агата |
| `compose.py` | язык партитуры (MML по тактам) -> `.YZ` |
| `pyplay.py` | эталонная модель движка |
| `mkdisk840.py` | ДОС 3.3 Агата на 840 КБ: каталог, запись и удаление файлов |
| `score/` | инструменты, помощники (`common.py`: аккорды, проверка гармонии) и части |

## Язык партитуры

Голос — строка вроде MML:

| Запись | Что |
|---|---|
| `o4`, `>`, `<` | октава, выше, ниже |
| `l8` | длительность по умолчанию |
| `c#4.` | нота с длительностью и точкой |
| `^16` | связка |
| `r` | пауза |
| `_e` | лига (без удара, со скольжением при `{porta}`) |
| `q6` | гейт 6/8 |
| `@инструмент` | инструмент |
| `{vib 0x53}` | эффект |
| `[...]3` | повтор |
| `\|` | проверка такта |

Ударные пишутся буквами набора (`instruments.py`: `KIT6`, `KIT7`) или номерами пресетов `=8:4`.
Управляющий канал задает темп (`set_tempo`, `ritard` — скорость строки подбирается так, чтобы тик был
около 100 Гц), свинг (`swing`: SPEED на каждой строке) и подписи на экран (`text`).
`common.check_harmony()` печатает ноты, которых нет в аккорде доли, — по ней проверялось
голосоведение.

## Ячейка на практике (замеры на модели eCat3)

- **Огибающие** (`measure.py`, канал 1, 440 Гц, узел F модели):
  - D4 — пик 3.2 В, за 300 мс спадает до 0.45 В, сброс D4 глушит за ~20 мс;
  - D5 — плавная атака (0 за 30 мс, 1 В за 120 мс, 1.9 В за 300 мс), удержание 2 В, отпускание
    ~0.1 с;
  - D4+D5 — 3.7 В и удержание ~3 В;
  - новый акцент — только после D4 = 0 не меньше 10 мс.
- **Уровни** (C3-C5, дБ от шкалы WAV):

  | Полосы, с D3 и D4+D5 | Уровень |
  |---|---|
  | НЧ+СЧ | -12..-13 |
  | НЧ | -13..-16 |
  | СЧ | -18..-21 |
  | ВЧ | -21..-27 |

  Без D3 на 8-10 дБ тише. На C6 полоса НЧ теряет ~8 дБ, ВЧ прибавляет.
- **Ударный 6** — тональный, 76-380 Гц:
  - `$08` бочка;
  - `$09`/`$0A` низкий том;
  - `$0B`/`$0C` средний;
  - `$0D` высокий с шумом;
  - `$0E`/`$0F` — «малый» (больше середины).

  D3 громче на 4-6 дБ и дольше: -20 дБ за 130 мс против 80-110.
- **Ударный 7** — шум 7-11 кГц, спад -20 дБ за 330-450 мс: `$08`/`$09` ~7 кГц, `$0A` ~8 кГц,
  `$0B` ~11 кГц.
- **Тембр от высоты**: ключ VT1 открывается на ~0.9 мс после каждого фронта счетчика. Ниже ~575 Гц
  звук импульсный, «носовой», выше — меандр.
