# 15ИЭ: проверки прошивки

`ie15_skip.py` - есть ли в прошивке терминала 15ИЭ-00-013 команда RAL или RAR (033, 035) сразу
после команды, которая может пропустить следующую (DSR, ISN, DSN, ISE, DSE, SFC/SFS/SKP, CS).

Эмулятор (`IE15CPU::skip()`) вслед за MAME пропускает двухбайтовую ячейку целиком, если
пропускаемый код из группы 03x, поэтому пропущенная RAL/RAR заберет и следующий байт. Как
поступает железо, по ТО не видно. Скрипт показывает, что вопрос не практический: в обеих
прошивках (`ie15.rom` и `ie15_6chip.rom`) такой пары нет ни в пройденном коде, ни где-либо в ПЗУ.

```
python tools/ie15/ie15_skip.py [ПЗУ...]
```

Без аргументов проверяет обе прошивки из `deploy/computers/dvk/files`. Код обходится от адреса 0
по переходам JMP, у команд с пропуском - по обеим ветвям; JMI переходит через регистр, поэтому
точками входа считаются и все константы LDC. Из-за этого часть данных проходится как код: два
неизвестных кода группы 03x, которые скрипт находит (077 по 3425, 071 по 4455, в шестичиповой - по
5055), - байты таблиц. На машине они не исполняются: после сценария `work-dvk1-ie15` счетчик
`ie15-cpu.unsupported` равен 0. Код возврата 1, если пара нашлась.
