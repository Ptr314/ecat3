# eCat3 — эмулятор ретрокомпьютеров в браузере

Это готовый к выкладке пакет: статические файлы, ничего больше. Ни сервера
приложений, ни базы, ни сторонних служб.

Эмулируются Орион-128, Радио-86РК, Спектр-001, Апогей, Микроша, Агат-7,
Агат-9, Ириша, Диалог, Каспий, Юниор, Арго, БК0010, БК0010-01, БК0011М и
УК-НЦ — тот же набор, что и в настольных сборках, без отладочных конфигураций.

## Как выложить

Положить содержимое каталога в корень сайта и раздавать статикой — но с
двумя обязательными заголовками, см. ниже.

**Из файловой системы (`file://`) страница не заведётся** — и это не изъян
сборки: браузер запрещает `fetch` и загрузку модуля WebAssembly с такого
происхождения.

### Два заголовка, без которых ничего не работает

Эмулятор собран с потоками (`-pthread`), а память между потоками в браузере
разделяется через `SharedArrayBuffer`. Он доступен только на «изолированном»
происхождении, и включают изоляцию ровно эти два заголовка:

```
Cross-Origin-Opener-Policy: same-origin
Cross-Origin-Embedder-Policy: require-corp
```

Без них страница загрузится и **молча встанет** на инициализации модуля.
Проверить, что изоляция включилась, можно в консоли браузера:

```js
crossOriginIsolated   // должно быть true
```

Плата за изоляцию: страницу нельзя вставить в чужой сайт через `<iframe>`.
И ещё: `SharedArrayBuffer` требует защищённого происхождения — `localhost`
считается таковым, а `http://` на настоящем домене нет. В сеть это
выкладывается только по HTTPS.

Пример настройки nginx с пояснениями — `nginx.conf.example`. Кроме
заголовков там ещё три вещи: тип `application/wasm` для `.wasm` (в nginx
старше 1.21.5 его надо добавить руками), сжатие и срок кэша.

### Кэш и новые выпуски

Имена файлов от выпуска к выпуску не меняются, поэтому страница просит каждый
с хэшем его содержимого в адресе (`ecat3.wasm?h=…`); хэши лежат в
`manifest.json`. При каждом открытии страница читает `manifest.json` мимо
кэша, и если сборка там другая — значит, из кэша пришла сама страница, — один
раз перезагружается по новому адресу (`?b=<сборка>`, остальные параметры
адреса сохраняются). Так посетитель получает новый выпуск без Ctrl+F5, а
неизменившиеся наборы машин не перекачивает.

От сервера нужно одно: не держать в кэше `index.html` и `manifest.json`
(`Cache-Control: no-cache`). Всё остальное можно отдавать с вечным сроком —
адрес меняется вместе с содержимым.

### Для пробы на своей машине

Обычный `python3 -m http.server` не годится — он не ставит COOP/COEP.
В репозитории рядом лежит сервер, который их ставит:

```
python3 src/wasm/serve_wasm.py <каталог пакета> 8080
```

## Что лежит в пакете

```
index.html  ecat_wasm.js       страница
ecat3.js  ecat3.wasm           сам эмулятор
machines.json                  список машин для меню
device_options.json            переводы переключателей машин (из src/translations)
tapefiles.ini                  как файлы магнитофона ложатся на ленту ([TapeFiles] из .ecat.ini)
manifest.json                  версия для подвала, метка сборки и хэши всех файлов
favicon.png                    значок вкладки — тот же, что у окна настольной версии
bundles/<машина>.bundle        ПЗУ, конфиг и образы дисков одной машины
bundles/data.bundle            общие таблицы знакогенераторов и раскладок
README.md  LICENSE.TXT  COPYRIGHT.TXT  nginx.conf.example
```

Наборы машин лежат в `bundles/` по одному файлу на машину, и страница тянет
только тот, который выбрали, — открывать её можно, не дожидаясь загрузки
всего. Путь до набора прописан в `machines.json`, так что переименовать
подкаталог можно, не трогая страницу.
Формат простой: для каждого файла путь с нулём на конце, размер четырьмя
байтами и содержимое подряд; пустое имя — конец архива. Собирает их
`src/wasm/package_machines.py` из каталога `deploy/`, так что добавить
машину можно, не трогая ни страницу, ни скрипт сборки: достаточно положить
`.cfg` с ПЗУ в `deploy/computers/` и пересобрать.

## Что умеет страница

- **Выбор машины** — из списка вверху; переключение перезагружает машину.
- **Reset** — тёплый сброс, **Power** — холодный, равносильный выключению и включению питания.
- **Громкость** — ползунком; звук идёт через Web Audio (miniaudio).
- **Load Disk** — подсунуть образ дискеты с машины: `.dsk`, `.mfm`, `.hfe`,
  `.nib`, `.nic`, `.aim`.
- **Магнитофон** — блок `tape` у машин с магнитофоном: загрузить запись,
  перемотать в начало, воспроизвести и поставить на паузу, записать то, что
  выводит машина (по остановке записи файл уходит в загрузки браузера),
  выключить звук ленты.
- **Загрузить файл** — программа в память машины в формате, который машина
  понимает сама, или файл целой машины: расширение конфигурации (`.ext`,
  `.ext.zip`) или сохранённое состояние (`.ecats`, `.ecats.zip`). Файл машины
  запускается так же, как по ссылке `load` (см. ниже), только из файла на
  компьютере посетителя. Кнопка есть у любой машины.

### Адрес страницы

Машину и вид страницы можно передать в адресе:

```
https://…/index.html?machine=Agat-7&kbd=1&scale=250&kbdscale=120
```

| Параметр | Что задаёт |
|---|---|
| `machine` | Машину: `id` из `machines.json` или имя файла конфигурации (`Agat-7.cfg`), регистр не важен |
| `load` | Ссылку на файл машины, которой в сборке нет, — расширение конфигурации (`.ext`, `.ext.zip`) или сохранённое состояние (`.ecats`, `.ecats.zip`): страница скачивает файл и запускает его, см. ниже |
| `kbd` | `1` — открыть экранную клавиатуру, если у машины есть её рисунок |
| `scale` | Масштаб экрана в процентах, 100–400 с шагом 25 |
| `aspect` | Форма экрана: `4x3` (или `4:3`) — как на телевизоре, `square` — квадратный экран, `1x1` (или `1:1`) — квадратные пиксели, каждая точка растра в целое число пикселей экрана |
| `filter` | Фильтрация при масштабировании: `none` — без неё (по умолчанию), `linear` — линейная, `sharp` — резкая: целая часть масштаба без фильтрации, линейно сглаживается только дробная |
| `kbdscale` | Размер клавиатуры в процентах, 50–200 с шагом 10, или `auto` — по ширине экрана |
| `blocks` | Свёрнутые и развёрнутые блоки боковых столбцов через запятую: имя блока — развёрнут, имя с минусом впереди — свёрнут (`blocks=machine,-screen,-fdd0`). Имена блоков страницы: `machine`, `screen`, `volume`, `language`, `file`, `keyboard`, `options`; блок дисковода или магнитофона зовётся по имени устройства (`fdd0`, `tape`). Блок, о котором в адресе не сказано, остаётся таким, каким его оставили в этом браузере |

Значение вне диапазона приводится к ближайшему допустимому.

Всё, что взято из адреса, действует только в этом визите и в сохранённые
настройки браузера не попадает: пришедший по чужой ссылке не теряет своих.
Машина, выбранная руками, сдвинутый ползунок и свёрнутый руками блок
сохраняются как обычно. Кнопка со звеньями цепи рядом с названием копирует в
буфер обмена адрес с текущими машиной, масштабами, состоянием клавиатуры и
тем, какие блоки на экране развёрнуты.

Машина, которая запускается сама — из адреса или оставшаяся с прошлого
визита, — ждёт первого щелчка или нажатия клавиши: страница показывает её
название и подсказку. Без действия пользователя браузер держит звук
выключенным, и начало работы машины, стартовый сигнал в том числе, пропало бы.
Машина, выбранная в списке, запускается сразу.

### Своя конфигурация по ссылке (`load`)

```
https://…/index.html?load=https://катал.ог/files/tdr.ext.zip
```

Страница скачивает этот файл, кладёт его в файловую систему эмулятора и
запускает как обычную машину; её название в списке &ndash; имя файла. Так с
сайта-каталога открывается конкретная программа: расширение задаёт образ диска
(файлом в _.ext.zip_ или прямо в тексте, `{base64: …}`), нужные настройки
машины и, если надо, сценарий автозапуска (`@script`). Формат описан в
`docs/CONFIG.md`.

Так же открывается и снимок состояния (_.ecats_, _.ecats.zip_): он несёт
машину целиком, с конфигурацией, ПЗУ и носителями, и базы в сборке ему не нужно.

Два условия:

- **База расширения должна быть машиной этой сборки.** Расширение строится поверх
  _.cfg_ или другого расширения (`@extends bk/BK-0011M.cfg`), а база и ПЗУ лежат в
  бандле своей машины: страница подгружает его перед запуском. Базы, которой в сборке
  нет, ждать неоткуда, и об этом будет сказано в строке состояния. Расширение,
  написанное под вариант, который был _.cfg_ и стал _.ext_ (`@extends
  bk/BK-0011M-fdd.cfg`), находит его по прежнему имени.
- **Сервер файла должен разрешить скачивание.** Страница работает в режиме
  cross-origin isolation (COOP/COEP), поэтому файл с чужого адреса нужен с
  заголовком `Access-Control-Allow-Origin` &ndash; иначе браузер не отдаст
  его странице. Файл, лежащий рядом со страницей, отдаётся без всяких условий.

Что не получилось &ndash; не скачалось, не тот файл, нет базы, ошибка в самом
расширении &ndash; пишется в строке состояния своими словами; список машин при
этом остаётся как был, и можно выбрать машину руками. Ничего вместо неудавшейся
машины не запускается.

Кнопка со звеньями цепи у такой машины копирует ссылку с тем же `load`.

### Программа по имени платформы (`platform`)

```
https://…/index.html?platform=БК0010&load=https://catalog.emuverse.ru/files/1373-terra1.zip
```

Так программу запускает каталог ПО: он передаёт файл программы и значение поля
«Платформа». По имени платформы таблица `launch/platforms.cfg` выбирает машину
сборки и сценарий запуска, а тот загружает программу и пускает её в том же
состоянии, что и монитор машины после загрузки с ленты. `machine` при этом не нужен и не
задаётся. Имя платформы сравнивается без учёта регистра и лишних пробелов;
параметр можно написать и как `PLATFORM`. Сейчас в таблице программы БК (_.bin_):
«БК0010», «БК0010 (11М)», «БК0010-01», «bk10» запускаются на БК0010-01,
«БК0011М», «БК0011», «bk11m» &ndash; на БК0011М. Образ дискеты БК (_.bkd_, _.img_) идёт на
той же машине с СМК-512: он вставляется в привод A:, и BIOS платы грузится с него сам.

`load` &ndash; сам файл программы или образа или архив _.zip_ с ним. В архиве берётся файл,
чьё имя без расширения совпадает с именем архива без числа с тире в начале
(`1373-terra1.zip` &rarr; `terra1.bin`), а если такого нет &ndash; единственный файл
типа, который платформа запускает. Сервер файла, как и выше, должен разрешить
скачивание.

В каталоге retro-catalog шаблон ссылки для eCat тогда такой:
`https://ecat.emuverse.ru/?load={url}&platform={meta:platform}`.

Неизвестная платформа, тип файла, которого она не запускает, архив без
программы &ndash; всё это пишется в строке состояния, и ничего не запускается.
Если машина запустилась, а файл не взяла (образ больше дискеты, испорченная
программа), строка состояния тоже говорит, что программа не запущена и почему.
Машина в сохранённый выбор не попадает: следующий визит без адреса откроет
машину, выбранную посетителем. Кнопка со звеньями цепи копирует ссылку с теми
же `platform` и `load`.

## Чем эта сборка отличается от настольной

- **Запись на дискету идёт только в память.** Файла у браузера нет, поэтому
  записанное живёт до перезагрузки страницы.
- **Отладчика, дизассемблера и просмотра памяти нет** — они сделаны на Qt, а
  в браузер идёт только Qt-независимое ядро эмулятора.
- **Сочетания, забранные самим браузером, до эмулятора не доходят.**
