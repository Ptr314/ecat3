# Библиотека программ

Образы дисков и лент, которые не входят в поставку эмулятора, но нужны: из них
собирается библиотека программ на сайте эмулятора (https://ecat.emuverse.ru/library/), и на них
работают тесты. Каталоги названы, как машины в `deploy/computers/`.

## Где взять

В git лежит только этот файл: образы - стороннее ПО, и в открытом репозитории их нет
(`.gitignore`). Они раздаются одним архивом `ecat3-library.zip` на странице
https://ecat.emuverse.ru/library/ - на неё же ссылаются описания машин. Архив
распаковывается в корень репозитория: внутри уже каталог `library/`.

Без него тесты, которым нужен образ отсюда, пропускаются: раннер называет недостающие
файлы и число пропущенных тестов (`tests/run_tests.py`, `tests/run_mcp_tests.py`).

Новый образ кладётся сюда вместе со своим `.lst`, архив пересобирается и выкладывается
на сайт заново: `.build\pack_library.cmd` (Windows, 7-Zip) или `python .build/pack_library.py`,
оба пишут `.build/release/ecat3-library.zip`.

## Что куда

- `deploy/software/` уходит в каждую сборку. Там лежит только то, что конфигурация
  загружает сама (`image =`, `disk_N =`), и маленькие ленты. Без такого образа машина
  стартует с пустым приводом, а веб-сборка теряет его: `src/wasm/package_machines.py`
  кладёт в бандл машины ровно названные в конфигурации файлы.
- Всё остальное - сюда. Скрипты сборки копируют только `deploy/`, этот каталог они не видят.
- Эмулятор здесь ничего не ищет. Сценарий называет файл от рабочего каталога `deploy/`:
  `COMMAND knmd.load("../library/e85/pros-2.03-10m.rd")`.
- Описания машин (`deploy/computers/**/*.md`, `docs/computers/`) называют эти образы по
  имени и отсылают к библиотеке на сайте, без пути в репозитории.
- К каждому образу приложен `<имя>.lst` (UTF-8): что на диске, откуда он взят, как его
  запустить в eCat3, формат, и список файлов с описаниями. Списки прочитаны с самих
  образов (Files-11, RT-11, FAT, каталог DOS), описания файлов - из того, что диск
  говорит о себе: имена программ в `.INS`, меню, справки, тексты вроде `INSTR.TXT`.
  Файл без описания - назначение которого не подтверждается ничем. Новый образ
  кладётся сюда вместе со своим `.lst`.

## Состав

| Каталог | Файлы | Содержимое |
|---|---|---|
| `e85` | `pros-2.03-10m.rd`, `pros-2.03-10m-pc.rd` | винчестер ПРОС 2.03 с играми, второй с «PC Эмулятором» для МС 1702 |
| | `pros-2.03-1-system.dsk` ... `-5-utilit.dsk` | установка ПРОС 2.03 на винчестер |
| | `tpo-1.dsk`, `tpo-2.dsk` | тестовые программы (ТПО) |
| | `igra.dsk`, `igra-color.dsk` | игры для НВ1 и для НВ2 |
| | `start-1.dsk` ... `start-5.dsk` | пакет СТАРТ |
| | `format-2.0.dsk` | «Форматирование дискет v 2.0» |
| | `emul-1.3.hfe` | «Эмулятор DOS v 1.3», дискета с метками F8 (рецепт - `tests/files/make-emul-1.3.ecat`) |
| | `eldos-*.dsk` | MS-DOS 3.30, утилиты, Chi-DOS 3.30, «PC Эмулятор в.1.1» |
| | `rt11v53.rd` | винчестер 32 МБ: RT-11 V05.03 фирмы DEC для Professional (тест `boot-e85-rt11`) |
| `dvk` | `rt11-dw.dsk` | RT-11 V05.04 на винчестере DW, 5 МБ |
| | `FODOSTMO.DSK` | ФОДОС, заводские тесты (ВМ2, ВМ3, MY, MX, DW, КГД, КЦГД) |
| `agat` | `INIT_HELLO840[a7].dsk`, `ikp2-19176.dsk` | диски Агата, которые не загружает ни одна конфигурация |
| `pravetz` | `sokoban.dsk`, `arkanoid.dsk`, `igra-i-matematika.nib` | игры с agatcomp.ru |
| `uknc` | `basic.dsk`, `basic.lst` | дисковый Бейсик и список файлов |
| | `wav2uknc.py` | перевод записи кассеты WAV в `.uknc.tap`; в git - `tools/uknc-tape/`, в архив кладётся сюда |
| `unior` | `pasc.a.bt`, `sc.a.bt` и их `.lst` | кассеты TCP/M: Pascal/MT+ 5.2, SuperCalc 1.12 |

В поставке у МС 0585 осталась одна дискета, `pros-d-1.8-system.dsk`: она стоит в
приводе 0 базовой конфигурации, а конфигурация с винчестером её убирает (с дискетой
автотест загружается с неё, а не с винчестера).
